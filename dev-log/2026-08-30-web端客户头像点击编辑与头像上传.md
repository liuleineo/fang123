# 2026-08-30 web 端客户头像点击编辑 + 头像上传

## 需求

`http://localhost:4000/customers` 客户列表，点击客户头像弹出编辑客户信息弹窗，支持上传/修改客户头像照片。

## 改动

### 后端（UserCustomerController.java）

- 新增 `PUT /api/user/customers/{id}` 接口：更新客户（仅本人），防止篡改 userId

### 前端（web/src/views/Customers.vue）

1. **头像可点击**：客户卡片头像区域支持显示客户照片，点击打开编辑弹窗（无照片时显示默认图标）
2. **编辑客户弹窗**：圆形头像预览 + 相机图标上传（`/user/upload` 上传后回填 URL），可修改姓名/手机号/意向/备注，保存调用 `PUT /user/customers/{id}` 后刷新列表
