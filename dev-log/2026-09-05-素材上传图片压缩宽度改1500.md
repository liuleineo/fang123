# 2026-09-05 素材上传图片压缩宽度 2000 → 1500

## 需求

`/admin/medias` 素材管理页面上传素材图片时，前端压缩宽度由 2000px 改为 1500px，高度保持自适应。

## 改动

`admin/src/views/LoupanMediaManage.vue`

- `compressImage()` 压缩上限 `w > 2000` → `w > 1500`，缩放基准 `2000` → `1500`
- 注释同步更新：`宽2000px` → `宽1500px`

该函数被页面内三种图片上传共用（点击上传 `uploadRequest`、Ctrl+V 粘贴上传 `uploadPasted`、批量上传），一处修改全部生效；高度仍按 `h = Math.round(h * 1500 / w)` 等比自适应。

## 注意

- 仅影响前端压缩，视频文件不走压缩逻辑，不受影响
- 需重新构建并部署 admin 前端生效
