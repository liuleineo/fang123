# 2026-08-13 首页新盘列表默认只展示在售楼盘

## 改动内容

`web/src/views/Home.vue`（首页 /#list 新盘列表）：

1. `fetchData(showAll = false)` 新增参数：默认（`showAll=false`）请求时附带 `salesStatus: '1'`（仅展示**在售**楼盘）；`showAll=true` 时不带筛选展示全部
2. 底部 CTA 按钮"浏览全部楼盘"点击改为 `fetchData(true)`，展示全部状态楼盘

## 交互效果

- 进入首页 /#list 默认只展示在售（salesStatus=1）的楼盘
- 点击底部"浏览全部楼盘"可查看全部状态楼盘

## 说明

- 已重新编译 web 端（`npm run build`）成功
- 若需线上生效，需将 `web/dist` 部署到线上服务器
