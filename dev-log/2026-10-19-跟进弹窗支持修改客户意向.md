# 2026-10-19 客户信息流：增加跟进时支持修改客户意向

## 需求

在客户信息流（`/customer-feed`）的「增加跟进」弹窗里，可以同时调整该客户的意向等级（高 / 中 / 低）。

## 实现（前端 `web/src/views/CustomerFeed.vue`）

**弹窗新增一行「意向」**：高 / 中 / 低 三个快捷按钮
- 打开弹窗时自动带出客户当前意向（选中态按等级着色：高=红、中=橙、低=灰蓝）；
- **再点一次已选中的等级 = 取消意向**（清空），与"未评级"对应；
- 旁边提示「再点可取消」，避免误以为不能撤销。

**提交逻辑** `submitFollow()`：
1. 先保存跟进记录（关键操作，必须成功）；
2. 再比较意向是否变化，变化时调 `PUT /user/customers/{id}`，body 只传 `{ intention }`；
3. 成功后同步更新当前客户卡片上的意向标签，并提示「已添加跟进，意向更新为「中」」/「已清除意向」；
4. **意向更新失败不阻断已保存的跟进**——被共享的客户只有归属人能改，此时提示
   「跟进已保存，但意向修改失败（仅客户归属人可修改意向）」。

后端无需改动：`PUT /user/customers/{id}` 内部用 `updateById`，MyBatis-Plus 默认忽略 null 字段，
只传 intention 不会覆盖姓名/手机号/备注；清空意向传空字符串即可（空串能正常写入）。

