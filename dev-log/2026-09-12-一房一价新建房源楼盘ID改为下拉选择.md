# 2026-09-12 一房一价管理：新建/编辑房源时楼盘ID 支持搜索选择

## 需求

管理端一房一价页（`/admin/yfyj`）新建房源时，楼盘ID 由手填数字改为下拉选择，沿用楼盘动态、媒体素材、预售证管理页的同一实现模式。

## 改动

### 前端 `admin/src/views/LoupanYfyjManage.vue`

- 新增楼盘下拉选项：
  - `loupanOpts` ref + `fetchLoupanOpts()`，调用 `GET /admin/loupans/options`
  - 选项 label 格式：`id · 楼盘名（行政区）`，value 为楼盘 id
- 新建/编辑房源弹窗中「楼盘ID」由 `t-input-number` 改为
  `<t-select filterable clearable :options="loupanOpts" placeholder="输入楼盘名称或ID搜索选择" />`
- `openCreate()` / `openEdit()` 打开弹窗时调用 `fetchLoupanOpts()` 拉取选项
- `onMounted` 改为 `fetchData()` + `fetchLoupanOpts()`，页面加载即预热选项

## 备注

- 后端接口 `GET /api/admin/loupans/options` 已存在（`LoupanController`），本次无后端改动
- 「AI 新建房源」弹窗的「关联楼盘ID」同步改为相同的可搜索下拉（`aiLoupanId`），打开弹窗时调用 `fetchLoupanOpts()`
- 列表顶部筛选框「楼盘ID」与「批量设置楼盘ID」弹窗保持数字输入不变
- 至此四个模块（媒体素材、预售证、楼盘动态、一房一价）的表单楼盘ID 选择方式已统一
