# 2026-08-24 新增楼盘动态（loupan_dynamic）模块

## 需求

基于 `loupan_dynamic` 表（楼盘建设/销售/优惠动态）实现 admin 端增删改查。

## 改动内容

### 数据库
- 本机创建 `loupan_dynamic` 表（表结构已在 schema.sql 中定义）

### 后端（新增4个文件）
1. `entity/LoupanDynamic.java`：实体（id/loupanId/title/content/type/images + deleted/createTime/updateTime）
2. `mapper/LoupanDynamicMapper.java`
3. `service/LoupanDynamicService.java` + `service/impl/LoupanDynamicServiceImpl.java`
4. `controller/LoupanDynamicController.java`：
   - `GET /api/admin/dynamics` 列表（分页 + 楼盘ID/类型/标题关键词搜索）
   - `GET /api/admin/dynamics/{id}` 详情
   - `POST /api/admin/dynamics` 新建
   - `PUT /api/admin/dynamics/{id}` 更新
   - `DELETE /api/admin/dynamics/{id}` 删除

### admin 前端（新增2个文件 + 2处修改）
1. 新增 `views/LoupanDynamicManage.vue`：列表 + 搜索（标题/楼盘ID/类型）+ 新建/编辑弹窗（标题/类型下拉/内容textarea/动态图片）
2. `router/index.js`：注册 `/admin/dynamics` 路由（name: LoupanDynamicManage，标题"楼盘动态"）
3. `layouts/AdminLayout.vue`：侧边栏新增"楼盘动态"菜单项（Megaphone 图标），位于"预售证"之后

### 动态图片上传增强（参照 medias 新建素材）
- 动态图片支持"选择上传"（t-upload 多选，经 /admin/medias/upload 压缩上传）和"粘贴上传"（Ctrl+V 粘贴截图，压缩上传）
- 已上传图片缩略图列表，可逐张删除；保存时逗号分隔写入 images 字段
