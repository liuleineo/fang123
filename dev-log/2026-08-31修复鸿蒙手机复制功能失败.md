# 2026-08-31 修复鸿蒙手机复制功能失败

## 问题

AI 沟通文案"复制文案"在电脑上复制成功，鸿蒙系统手机上测试失败。

## 原因

`navigator.clipboard`（Clipboard API）是较新的 Web 标准，要求 HTTPS 安全上下文，各端支持不一致：
- PC 现代浏览器支持
- 安卓 Chrome / iOS Safari 14+ 支持
- **鸿蒙浏览器/WebView、微信内置浏览器兼容性差，`navigator.clipboard` 常为 undefined**，直接调用即抛异常

## 修复

### 新增 `web/src/utils/clipboard.js`

兼容复制工具 `copyText(text)`：
1. 优先使用 Clipboard API（`navigator.clipboard && isSecureContext`）
2. 失败/不支持时降级为 `document.execCommand('copy')` + 临时 textarea + 选中范围（全平台 WebView 通用）

### 应用

- `Customers.vue`：`copyAiCopy`（AI 沟通文案复制）改用 `copyText`，失败提示改为"请长按内容手动复制"
- `Profile.vue`：`copyInviteUrl`（邀请链接复制）同样改用 `copyText`

## 验证

- web 编译通过（真实鸿蒙设备需线上验证）
