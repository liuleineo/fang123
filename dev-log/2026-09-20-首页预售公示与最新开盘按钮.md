# 2026-09-20 首页新增「预售公示 / 最新开盘」两个按钮（含数量角标）

## 需求

在首页搜索框下方增加两个按钮：**预售公示**、**最新开盘**，按钮右上角展示满足条件的楼盘数量，点击后下方列表展示对应楼盘。

筛选规则（数据源：预售证信息表 `loupan_presale_permit`）：

| 板块 | 条件 |
| --- | --- |
| 预售公示 | `publicity_date >= 今天` 且 `publicity_date < issue_date`（已进入/即将进入公示期、尚未核发） |
| 最新开盘 | `issue_date >= 今天` 且 `issue_date < 今天 + 8 天`（未来 8 天内核发预售证的新盘） |

## 后端改动

### 1. 新增 DTO `dto/LoupanSpotlightVO.java`

楼盘卡片所需精简字段 + 预售证关键字段：`id`、`encodedId`、`projectName`、`coverImage`、`district`、`plate`、`brandList`、各均价、`areaMin/areaMax`、`houseType`、`decorateType`、`salesStatus`、`buildingTotal`、`publicityDate`、`issueDate`、`permitNoStr`。

### 2. 新增 `controller/LoupanSpotlightController.java`

| 接口 | 说明 |
| --- | --- |
| `GET /api/public/loupan-spotlight/counts` | 返回 `{ presale: n, opening: n }`，供按钮右上角角标使用 |
| `GET /api/public/loupan-spotlight?type=presale\|opening&page=1&size=12` | 返回 `{ type, total, page, size, records[] }` 分页列表 |

实现要点：

- 先按日期条件查预售证（`LoupanPresalePermitService`，逻辑删除由 MyBatis-Plus 自动过滤），同楼盘多张证按日期排序后只保留最靠前一张；
- 再按 `loupan_id` 关联楼盘，过滤掉已删除/不存在的楼盘，因此**统计数量与列表数量口径一致**；
- 排序：预售公示按公示日期升序；最新开盘按核发日期升序（越早开盘越靠前）；
- 单页最大 60 条（`MAX_PAGE_SIZE`）；`type` 非法返回 400；
- `/api/public/**` 已在 `SecurityConfig` 放行，无需额外配置。

### 3. `db/schema.sql` 补充索引

```sql
KEY `idx_publicity_date` (`publicity_date`) COMMENT '公示日期（首页-预售公示筛选）',
KEY `idx_issue_date` (`issue_date`) COMMENT '核发日期（首页-最新开盘筛选）'
```

本机已执行：

```sql
ALTER TABLE loupan_presale_permit
  ADD KEY idx_publicity_date (publicity_date),
  ADD KEY idx_issue_date (issue_date);
```

## 前端改动：`web/src/views/Home.vue`

1. 搜索框下方新增两个卡片式按钮（`grid-cols-2`），右上角 absolute 圆形角标显示数量（`spotlightCounts`）；
2. 点击按钮 → `toggleSpotlight(type)` → 调用板块接口 → 复用下方列表区渲染，卡片额外显示「公示 2026-09-21」「核发 2026-09-29」标签；
3. 再次点击同一按钮或点击提示条右侧「返回全部楼盘」退出板块模式；手动搜索/切换筛选条件也会自动退出；
4. 空状态文案按板块区分：`暂无公示中的楼盘` / `近 8 天暂无新取证楼盘`；
5. 分页复用原 `t-pagination`，板块模式下 `fetchData()` 自动转发到板块接口。

## 线上部署提示

1. 后端：部署新 jar 并重启；
2. web：`npm run build` 后部署 `web/dist`；
3. 线上库需执行上面的 `ALTER TABLE ... ADD KEY` 索引语句（可选，仅性能优化）；
4. **线上数据前提**：`loupan_presale_permit` 中 `publicity_date`、`issue_date`、`loupan_id` 必须已填充，且 `loupan_id` 能对应到 `loupan` 表记录，否则角标显示 0。当前线上仅部分预售证（如楼盘 109 沐澄月轩 id 26516）有日期与关联，需要补全剩余数据的解析/导入。
