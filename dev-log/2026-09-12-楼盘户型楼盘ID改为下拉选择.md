# 2026-09-12 楼盘户型管理：新建/编辑户型及 AI 新建户型 楼盘ID 支持搜索选择

## 需求

管理端楼盘户型页（`/admin/huxings`）新建户型时，楼盘ID 由手填数字改为下拉选择，沿用楼盘动态、媒体素材、预售证管理、一房一价页的同一实现模式。

## 改动

### 前端 `admin/src/views/LoupanHuxingManage.vue`

- 新增楼盘下拉选项：
  - `loupanOpts` ref + `fetchLoupanOpts()`，调用 `GET /admin/loupans/options`
  - 选项 label 格式：`id · 楼盘名（行政区）`，value 为楼盘 id
- 新建/编辑户型弹窗中「楼盘ID」由 `t-input-number` 改为
  `<t-select filterable clearable :options="loupanOpts" placeholder="输入楼盘名称或ID搜索选择" />`
- 「AI 新建户型」弹窗的「关联楼盘ID」同步改为相同的可搜索下拉（`aiLoupanId`）
- `openCreate()` / `openEdit()` / `openAiDialog()` 打开弹窗时调用 `fetchLoupanOpts()` 拉取选项
- `onMounted` 改为 `fetchData()` + `fetchLoupanOpts()`，页面加载即预热选项

## 备注

- 后端接口 `GET /api/admin/loupans/options` 已存在（`LoupanController`），本次无后端改动
- 列表顶部筛选框「楼盘ID」保持数字输入不变
- 至此五个模块（媒体素材、预售证、楼盘动态、一房一价、楼盘户型）的表单楼盘ID 选择方式已统一
