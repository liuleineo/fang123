# 2026-09-20 楼盘增加开盘时间字段

## 需求

`loupan` 表在 `delivery_date`（交房时间）前增加 `opening_date`（开盘时间）字段。

## 改动内容

### 1. schema.sql

在 `loupan` 表 `delivery_date` 之前新增：

- `opening_date` date DEFAULT NULL COMMENT '开盘时间'

### 2. 实体 Loupan.java

- 新增字段 `openingDate`（`LocalDate`，使用 `LenientLocalDateDeserializer` 兼容 `2026-08` / `2026年8月` 等宽松格式）
- `computeCompletionRatio()` 完善度统计纳入开盘时间

### 3. AI 解析（AiParseResult + AiParseService）

- `AiParseResult.ParsedFields` 新增 `openingDate`
- 解析提示词新增 `"openingDate": "开盘时间，格式YYYY-MM-DD"`

### 4. admin LoupanManage.vue

- 建筑指标 tab："开盘时间"日期选择器，与"交房时间"同行展示
- `initForm()` 添加 `openingDate: ''`
- `fieldLabels` 添加"开盘时间"（AI 识别结果预览与填入）
- 抽出 `normalizeDateStr()`，开盘时间与交房时间统一做 yyyy-MM-dd 规范化

### 5. web LoupanDetail.vue

- 详情页"基本信息"新增"开盘时间"展示（有值才显示）

### 6. 数据库

本机 `fang123.loupan` 已执行：

```sql
ALTER TABLE `loupan` ADD COLUMN `opening_date` date DEFAULT NULL COMMENT '开盘时间' AFTER `show_house_desc`;
```
