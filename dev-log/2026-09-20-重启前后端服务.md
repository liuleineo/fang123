# 2026-09-20 重启后端 / web / admin 服务

## 背景

`loupan` 表新增 `opening_date`（开盘时间）字段，需要重启服务使改动生效。

## 启动方式（本机开发环境，后台运行 + 日志重定向）

```bash
# 后端（端口 8090）
cd /Users/neo/neocode/fang123/backend
nohup java -jar target/fang123-backend-1.0.1-SNAPSHOT.jar > /tmp/fang123-backend.log 2>&1 &

# web 端（端口 4000，/api 代理到 8090）
cd /Users/neo/neocode/fang123/web
nohup npm run dev > /tmp/fang123-web.log 2>&1 &

# admin 端（端口 3000，/admin/ 前缀，/api 代理到 8090）
cd /Users/neo/neocode/fang123/admin
nohup npm run dev > /tmp/fang123-admin.log 2>&1 &
```

## 启动结果

| 服务 | 端口 | 进程 PID | 状态 |
| --- | --- | --- | --- |
| 后端 | 8090 | 88171 | Started Fang123Application in 3.065s |
| web | 4000 | 88205 | VITE v5.4.11 ready in 455ms |
| admin | 3000 | 88241 | VITE v5.4.11 ready in 361ms |

访问地址：
- web：http://localhost:4000/
- admin：http://localhost:3000/admin/
- 后端：http://localhost:8090/

## 环境

- Java 21.0.10 (Temurin)、Node v24.13.0、npm 11.6.2

## 备注

- 日志文件：`/tmp/fang123-backend.log`、`/tmp/fang123-web.log`、`/tmp/fang123-admin.log`
- 停止服务：`kill <PID>`（或 `lsof -nP -iTCP:8090 -sTCP:LISTEN` 查 PID）
