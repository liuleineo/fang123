# 2026-10-30 管理端土拍地块：列表增加「查看地块」外链

## 需求

管理端 `/admin/tupai-lands` 土拍地块列表，在数据后面加一个「查看地块」链接，跳转浙江自然资源交易平台：

`https://www.zjzrzyjy.com/landView/land-bidding/source-detail?resourceId={resourceId}`

## 改动（`admin/src/views/LoupanTupaiLandManage.vue`）

- 操作列（表格最右侧、紧跟数据列）新增「查看地块」，排在 编辑 / 删除 之前
- 用原生 `<a>` 而不是按钮，`target="_blank"` + `rel="noopener noreferrer"`，支持新标签打开 / 中键新窗口
- 链接地址由行数据的 `resourceId` 拼出：

```js
const LAND_DETAIL_BASE = 'https://www.zjzrzyjy.com/landView/land-bidding/source-detail?resourceId='
function landDetailUrl(row) {
  return LAND_DETAIL_BASE + encodeURIComponent(row?.resourceId || '')
}
```

- `resourceId` 为空的行不渲染链接（避免点开一个只有 `?resourceId=` 的无效页）
- 操作列宽度 120 → 170，容纳三个操作项不换行
