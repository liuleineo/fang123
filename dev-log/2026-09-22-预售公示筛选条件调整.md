# 2026-09-22 首页「预售公示」筛选条件调整

## 需求

`http://localhost:4000/` 首页「预售公示」板块：核发日期 < 今日，且公示日期 >= 今日。

## 改动文件

`backend/src/main/java/com/fang123/controller/LoupanSpotlightController.java`

### 1. `presalePermits(LocalDate today)`

| | 条件 |
| --- | --- |
| 改前 | `publicity_date >= today` 且 `publicity_date < issue_date` |
| 改后 | `issue_date < today`（尚未核发）且 `publicity_date >= today` |

```java
.isNotNull(LoupanPresalePermit::getIssueDate)
.lt(LoupanPresalePermit::getIssueDate, today)
.isNotNull(LoupanPresalePermit::getPublicityDate)
.ge(LoupanPresalePermit::getPublicityDate, today)
```

原 `.apply("publicity_date < issue_date")` 已移除；排序（`publicity_date` 升序、`id` 降序）保持不变。

### 2. 类 Javadoc

预售公示规则说明同步更新为「核发日期 < 今天（尚未核发）且 公示日期 >= 今天」。`counts` 与 `list` 共用 `presalePermits`，两处口径自动一致，前端角标与列表同步变化。

## 验证（今天 = 2026-09-22）

编译：`mvn -B -ntp compile` → BUILD SUCCESS（spring-boot-devtools 已热重启生效）。

SQL 交叉验证：

```sql
-- 新规则
SELECT COUNT(*) FROM loupan_presale_permit
WHERE loupan_id IS NOT NULL AND issue_date < CURDATE() AND publicity_date >= CURDATE();  -- 0
-- 旧规则
SELECT COUNT(*) FROM loupan_presale_permit
WHERE loupan_id IS NOT NULL AND publicity_date >= CURDATE() AND publicity_date < issue_date;  -- 1
```

接口 `GET /api/public/loupan-spotlight/counts` → `{"presale":0,"opening":1}`，与**新规则**一致（旧规则时为 1），确认改动已生效。
