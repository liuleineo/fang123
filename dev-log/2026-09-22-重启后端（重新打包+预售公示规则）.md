# 2026-09-22 重启后端（重新打包，含预售公示规则更新）

## 背景

8090 上运行的后端是 `java -jar target/fang123-backend-1.0.1-SNAPSHOT.jar`，jar 打包时间为 09-20 22:51，而 `LoupanSpotlightController.java`（预售公示筛选条件）在 09-22 有改动，源码比 jar 新。直接重启会导致改动回退，因此**先重新打包再重启**。

## 操作

1. 比对源码与 jar 时间：`find src \( -name "*.java" -o -name "*.yml" \) -newer target/*.jar`
   → 仅 `LoupanSpotlightController.java` 较新。
2. 重新打包：`mvn -B -ntp -q clean package -DskipTests`
   → `target/fang123-backend-1.0.1-SNAPSHOT.jar`（67M，10:21）。
3. 停止旧进程（PID 91743，原日志 `/tmp/fang123-backend.log`），等待 8090 端口释放。
4. 以相同方式后台启动：`nohup java -jar target/fang123-backend-1.0.1-SNAPSHOT.jar > backend/logs/backend.log 2>&1 &`
