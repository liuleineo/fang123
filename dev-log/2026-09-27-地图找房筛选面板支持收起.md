# 2026-09-27 地图找房页（/map）筛选面板支持收起（对标土拍地图）

## 需求

`http://localhost:4000/map` 左侧筛选/楼盘列表面板支持收起，交互参照土拍地图（`TupaiMap.vue`）的地块列表。

## 现状与差异

`TupaiMap.vue`（对标实现）：

- 开关按钮 `absolute top-4 left-4 z-20`，**全端可见**（无 `md:hidden`），文案 `showPanel ? '关闭列表' : '地块列表'`
- 面板 `absolute top-14 left-4`，`:class="showPanel ? 'flex' : 'hidden'"` → **全端默认收起**
- `showPanel = ref(false)`

`MapSearch.vue`（改前）：

- 开关按钮带 `md:hidden` → 桌面端看不到按钮
- 面板 `top-14 md:top-4` + `:class="showPanel ? 'flex' : 'hidden md:flex'"` → 桌面端**常驻展开、无法收起**，且与按钮在 `top-4` 处视觉重叠

## 改动

`web/src/views/MapSearch.vue`（仅模板层，脚本未动，`showPanel = ref(false)` 已有）：

1. 开关按钮去掉 `md:hidden`，全端可见；注释改为「侧边筛选面板开关按钮（全端可见，默认收起）」
2. 面板位置统一为 `top-14 left-4`（去掉 `md:top-4`，避免与开关按钮重叠）
3. 面板显隐改为 `:class="showPanel ? 'flex' : 'hidden'"`（去掉 `hidden` 的 `md:flex` 例外），即桌面端同样可收起
4. 高度上限统一为 `max-h-[calc(100vh-var(--header-height)-5rem)]`（去掉 `md:` 变体，与土拍一致）
5. 注释同步为「侧边筛选面板（默认收起，点击按钮展开/收起；交互与土拍地图地块列表一致）」

按钮文案沿用本页既有语义「楼盘列表 / 关闭列表」，未改动；面板内部搜索、行政区/类型筛选、列表项、详情跳转均未改动。

## 验证

浏览器实测 `http://localhost:4000/map`（桌面视口）：

```json
{"init":{"btn":"楼盘列表","visible":false}}
{"after1":{"btn":"关闭列表","visible":true}}
{"after2":{"btn":"楼盘列表","visible":false}}
```

- 默认收起，开关按钮文案为「楼盘列表」 ✓
- 点击后展开，文案变「关闭列表」 ✓
- 再次点击收起 ✓
- Lint（MapSearch.vue）：0 error ✓
