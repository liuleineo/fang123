# 2026-09-27 客户列表（/customers）分页默认 20 条，可选 20/50/100

## 需求

`https://hangfang123.com/customers` 默认每页展示 20 条数据，每页条数可在 20 / 50 / 100 之间选择。

## 改动（`web/src/views/Customers.vue`）

1. 默认每页条数：`const pg = reactive({ current: 1, pageSize: 10 })` → `pageSize: 20`
2. 分页组件新增每页条数选项：`<t-pagination … :page-size-options="[20, 50, 100]" …>`

配置与后端一致，无需改动后端：`UserCustomerController#page` 的 `size` 无上限校验（`new Page<>(page, size)`），传 100 正常返回。

> TDesign 侧确认：`tdesign-vue-next` v1.20.1 的 `pageSizeOptions` 默认 `[5,10,20,50]`、`showPageSize` 默认 `true`，因此只需传入选项数组即可显示下拉。

## 验证（本地 dev，实测数据）

后端运行于 `localhost:8090`（dev profile，本地 MySQL），web dev server `localhost:4000`。注册临时用户并在其下创建 25 条客户数据后实测：

| 项 | 结果 |
|---|---|
| 默认每页 | 渲染 20 张卡片，分页显示「共 25 条数据 1 2」，每页条数显示「20 条/页」 ✅ |
| 下拉选项 | 真实点击后选项为「20 条/页 / 50 条/页 / 100 条/页」 ✅ |
| 切换到 100 | 列表渲染 25 条（全量数据） ✅ |
| 刷新页面 | 回到默认「20 条/页」 ✅ |

验证数据已清理：25 条测试客户 + 1 个测试用户（手机号 13900001234）已从本地 dev 库删除，复核计数均为 0。
