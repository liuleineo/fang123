# 2026-09-07 素材管理楼盘ID支持搜索楼盘名称选择

## 需求

管理端媒体素材（`/admin/medias`）"新建素材/新建视频素材/批量新建素材"及编辑时，楼盘ID 不再手填数字，改为可搜索楼盘名称选择后填入。

## 改动

`admin/src/views/LoupanMediaManage.vue`：

1. 新增 `loupanOpts` + `fetchLoupanOpts()`，复用已有接口 `GET /api/admin/loupans/options`（返回 id/projectName/district），选项展示为 `id · 楼盘名（行政区）`
2. 三个"楼盘ID"输入框由 `t-input-number` 改为 `t-select`（`filterable` 支持输入楼盘名/ID 过滤、可清空）
3. `openCreate` / `openVideoCreate` / `openEdit` 打开时刷新选项，`onMounted` 预载

## 备注

- 仅前端改动，纯前端可测试；生产部署重新上传 `admin/dist` 即可
