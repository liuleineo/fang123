# 2026-09-27 学校地图（/school-map）学校列表支持收起

## 需求

`http://localhost:4000/school-map` 的学校列表面板支持收起，交互与地图找房（`MapSearch.vue`）、土拍地图（`TupaiMap.vue`）保持一致。

## 现状

`SchoolMap.vue` 的学校列表为 `hidden md:flex absolute top-3 left-3 bottom-3 w-[320px]` —— 桌面端常驻展开、无法收起；手机端 `hidden` 直接隐藏，**完全没有列表入口**。无 `showPanel` 状态。

## 改动（`web/src/views/SchoolMap.vue`）

### 模板

1. 新增左上角开关按钮（全端可见，圆角胶囊样式与另两页一致）：
   - `absolute top-3 left-3 z-40`，覆盖在面板（`z-30`）之上，不与面板重叠
   - `SlidersHorizontal` 图标 + 文案 `showPanel ? '关闭列表' : '学校列表'`
2. 列表面板 class 由 `hidden md:flex ... top-3` 改为：
   - 位置：`absolute top-14 left-3 bottom-3`（下移，给开关按钮让位，与另两页 `top-14` 对齐）
   - 宽度：`w-[320px] max-w-[calc(100vw-1.5rem)]`（新增窄屏保护，避免手机端溢出）
   - 显隐：`:class="showPanel ? 'flex' : 'hidden'"`（全端可收起/展开，去掉 `hidden md:flex`）
3. 注释更新为「学校列表开关按钮（全端可见，默认收起）」「侧边栏：学校列表（默认收起…）」

### 脚本

- `import` 增加 `SlidersHorizontal`
- 新增 `const showPanel = ref(false)`（默认收起，与另两页一致）

未改动：顶部筛选栏、搜索、卫星切换、标记渲染、`focusSchool` 等逻辑。面板内「学校列表 N所」标题与列表项保持原样。

## 验证

浏览器实测 `http://localhost:4000/school-map`：

```json
{"init":{"btn":"学校列表","visible":false,"count":543}}
{"after1":{"btn":"关闭列表","visible":true,"count":543}}
{"after2":{"btn":"学校列表","visible":false},"mapOk":true}
```

- 默认收起，开关按钮文案「学校列表」 ✓
- 点击后展开（543 所学校正常渲染），文案变「关闭列表」 ✓
- 再次点击收起 ✓
- 地图容器正常渲染 ✓
- Lint（SchoolMap.vue）：0 error ✓

## 顺带收益

手机端此前看不到学校列表，现在通过开关按钮可在手机上展开/收起列表。
