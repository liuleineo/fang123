# 2026-09-02 楼盘真实成交页增加"同板块真实成交"

## 需求

`/loupan/:id/real-deal` 真实成交页面下方，增加"同板块内真实成交信息，最近 30 条"。

## 改动

### 后端（LoupanPublicController.java）

- 新增 `GET /api/public/loupans/{encodedId}/real-deals/plate` 接口：
  - 板块定位：优先取本楼盘成交记录中的 `plate`，无成交则回退 `loupan` 表 `plate` 字段
  - 查询同板块成交（`deleted=0`）：排除本楼盘（`loupanId=id`），保留其他楼盘及未关联楼盘的记录（`loupanId is null`）
  - 按成交时间倒序，`LIMIT 30`
  - 返回 `{ plate, records }`

### 前端（web/src/views/LoupanSubPage.vue）

- real-deal 分支主表格下方新增"同板块真实成交"区块：
  - 标题 + 板块标签（如"金沙湖"）+ "最近 N 条"
  - 表格列：成交时间 / 小区 / 房号 / 面积 / 成交单价 / 成交总价 / 备注
  - 无板块或无数据时显示空态提示
- 新增 `fetchPlateDeals`，进入 real-deal 页面时与主成交列表一起加载

## 验证

- 后端编译重启成功，端到端实测：楼盘（金沙湖板块）同板块接口返回 plate="金沙湖" + 2 条成交（含未关联楼盘的成交，本楼盘自身成交被排除），测试数据已清理
- web 编译通过，dev 已热更新
