# 2026-09-27 水印透明度由 35% 调整为 30%

## 需求

「同板块真实成交」表格的水印透明度改为 30%。

## 改动文件

`web/src/views/LoupanSubPage.vue`

| 位置 | 改动前 | 改动后 |
| --- | --- | --- |
| `WATERMARK_COLOR` 常量（约 371 行） | `rgba(255, 0, 0, 0.35)` | `rgba(255, 0, 0, 0.30)` |
| 弹窗提示文案（约 306 行） | 「…红色，透明度 35%。留空并确认可移除水印。」 | 「…红色，透明度 30%。留空并确认可移除水印。」 |
| 模板注释（约 290 行） | 透明度 35% | 透明度 30% |
| 逻辑注释（约 370 行） | 透明度 35% | 透明度 30% |

说明：水印为 canvas 生成的平铺底图，`ctx.fillStyle = WATERMARK_COLOR`，因此只需改常量即可全局生效（文字填充 alpha 由 `0.30` 控制，无需额外 `globalAlpha`）。原有 `-45°` 旋转、`repeat` 平铺、`pointer-events: none` 均不变。

## 验证

- `read_lints` → 0 报错
- `web && npm run build` → 成功（9.54 s），退出码 0

## 备注

前端需重新部署后线上生效。
