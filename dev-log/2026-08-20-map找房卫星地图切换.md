# 2026-08-20 地图找房（/map）增加卫星地图切换按钮

## 改动内容

`web/src/views/MapSearch.vue`（/map 地图找房页面）：

1. 地图容器右下角新增"卫星/地图"切换按钮（白底 + Map/Satellite 图标）
2. 地图初始化时创建卫星图层 `AMap.TileLayer.Satellite` 和道路标注 `AMap.TileLayer.RoadNet`（默认不显示）
3. 新增 `showSatellite` ref 和 `toggleSatellite()` 函数：`map.add/remove` 切换卫星图
4. 图标导入：`Map` 重命名为 `MapIcon`，新增 `Satellite as SatelliteIcon`，模板中 `<Map>` 同步改为 `<MapIcon>`

## 交互效果

地图找房右下角点击"卫星"切换卫星影像（叠加道路标注），再点切回标准地图。与 school-map 页面行为一致。

## 说明

- 已重新编译 web 端（`npm run build`）成功
- 若需线上生效，需将 `web/dist` 部署到线上服务器
