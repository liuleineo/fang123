# 2026-11-13 真实成交表增加「挂牌价」字段

## 需求

`real_deal_info`（真实成交）在房间面积后增加「挂牌价」字段，用于记录业主挂牌价，与最终成交价对比。

## 改动

### 1. 表结构 `backend/src/main/resources/db/schema.sql`

`real_deal_info` 的 `house_area` 之后、`deal_price` 之前新增：

```sql
`listing_price` decimal(12,2) NOT NULL DEFAULT 0.00 COMMENT '挂牌价，单位万元',
```

本地库已执行：

```sql
ALTER TABLE real_deal_info
  ADD COLUMN listing_price decimal(12,2) NOT NULL DEFAULT 0.00 COMMENT '挂牌价，单位万元' AFTER house_area;
```

> 线上库需同步执行上述 ALTER。

### 2. 后端

- `entity/RealDealInfo.java`：新增 `BigDecimal listingPrice`（驼峰自动映射 `listing_price`）
- `dto/AiParseRealDealResult.RealDealFields`：新增 `Double listingPrice`

### 3. AI 解析（`service/AiParseService.java`）

- `REAL_DEAL_PARSE_PROMPT` 返回结构中新增：
  `"listingPrice": "挂牌价格（业主挂牌价），万元，纯数字，若文本包含否则null"`
- 规则 2 原先明确「不要返回挂牌价格」，改为只排除维护门店、完整地址
- 新增规则 7：区分挂牌价与成交价（`挂牌价格/挂牌价/报价/委托价` → `listingPrice`），无挂牌价则 null
- 新增 `normalizeRealDealNumbers(JsonNode)`：把 AI 返回的 `2180万` 这类字符串统一去单位转数字（houseArea / listingPrice / dealPrice / yfyj / loupanId），避免反序列化失败；`parseRealDealFromText` 改为先 `readTree` → 归一化 → `treeToValue`

### 4. Excel 批量导入（`controller/RealDealInfoController.java`）

- 新增表头列识别：`挂牌` / `报价` → `listingCol`
- 数值校验与提示扩展为「面积/挂牌价/成交价/一手价需为数字」
- 入库时 `setListingPrice(...)`
- 模板表头示例更新为：`成交日期|行政区|板块|小区名称|房号|面积|挂牌价|成交价|一手买入价|楼盘ID|备注`

### 5. 管理端（`admin/src/views/RealDealManage.vue`）

- 列表新增「挂牌价」列（面积与成交单价之间，`-` 表示未填）
- 新建/编辑表单：`房间面积` + `挂牌价` 同一行，`成交价` + `一手买入价` 下一行，楼盘ID 单独一行
- AI 识别结果面板：`房源面积` + `挂牌价`、`成交价格` + `一手买入价` 两行
- `confirmAiFill()` 映射 `listingPrice`，`initForm()` 增加 `listingPrice: null`
- Excel 导入弹窗的字段说明与模板示例加上挂牌价

### 6. 未改动

前台 `web` 端真实成交表格（本楼盘 / 同板块）未展示挂牌价，如需对访客公开可再补一列。
