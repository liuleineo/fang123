# 2026-09-12 预售证管理：新建/编辑时楼盘ID 支持搜索选择

## 需求

管理端预售证页（`/admin/presale-permits`）新建预售证时，楼盘ID 由手填数字改为下拉选择，实现方式参照「媒体素材 → 新建素材」的楼盘ID 选择。

## 改动

### 前端 `admin/src/views/PresalePermitManage.vue`

- 新增楼盘下拉选项（与 `LoupanMediaManage.vue` 完全一致的实现）：
  - `loupanOpts` ref + `fetchLoupanOpts()`，调用 `GET /admin/loupans/options`
  - 选项 label 格式：`id · 楼盘名（行政区）`，value 为楼盘 id
- 新建/编辑弹窗中「楼盘ID」由 `t-input-number` 改为
  `<t-select filterable clearable :options="loupanOpts" placeholder="输入楼盘名称或ID搜索选择" />`
- `openCreate()` / `openEdit()` 打开弹窗时调用 `fetchLoupanOpts()` 拉取选项
- `fillFormFromAi()`（AI 识别后填入表单）打开弹窗时同样拉取选项
- `onMounted` 改为 `fetchData()` + `fetchLoupanOpts()`，页面加载即预热选项

## 备注

- 后端接口 `GET /api/admin/loupans/options` 已存在（`LoupanController`），本次未做后端改动
- 列表顶部的筛选框「楼盘ID」保持数字输入不变，仅调整表单录入方式
