# 2026-09-01 修复 AI 新建楼盘保存 500

## 问题

`https://hangfang123.com/admin/loupans` AI 识别填入后点保存，`POST /api/admin/loupans` 返回 500。

## 根因

AI 返回的字段值类型与后端 `Loupan` 实体字段类型不匹配，Jackson 反序列化失败：

| 请求体值 | Loupan 字段类型 | 报错 |
|---|---|---|
| `deliveryDate: "2026-08"`（AI 识别的"2026年8月"） | `LocalDate` | `DateTimeParseException: Text '2026-08' could not be parsed` |
| `landBuyDate: ""` | `LocalDate` | 空串无法解析 |
| `longitude: ""` / `latitude: ""` | `BigDecimal` | 空串无法解析 |

## 修复

### 后端

1. **`application.yml`**：新增 `spring.jackson.deserialization.accept-empty-string-as-null-object: true`，空字符串一律按 null 处理（解决 `""` → BigDecimal/LocalDate 报错）

2. **新增 `util/LenientLocalDateDeserializer.java`**：宽松 LocalDate 反序列化器，兼容 `"2026-08"`（自动补日 01）、`"2026年8月"`、`"2026-08-01"`、空串等格式，无法解析返回 null 不抛错

3. **`Loupan.java`**：`deliveryDate`、`landBuyDate` 两个字段加 `@JsonDeserialize(using = LenientLocalDateDeserializer.class)`

### 前端（admin/src/views/LoupanManage.vue）

- `fillFormFromAi`：AI 填入的交房时间规范化，`"2026-08"` / `"2026年8月"` → `"2026-08-01"`（表单日期选择器可正常显示）

## 验证

- 后端编译重启成功；用线上同款请求体（含 4 个问题字段）实测 `POST /api/admin/loupans` → code 200 创建成功，测试数据已清理
- admin 编译通过
