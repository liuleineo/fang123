# 2026-09-27 客户列表：头像下方显示未跟进天数

## 需求

`/customers` 客户列表，在客户头像下面增加一个天数数字：显示该客户多少天未跟进；若该客户没有任何跟进记录，则按「距创建时间的天数」计算。

## 改动（`web/src/views/Customers.vue`）

### 1. 模板：左栏改为「头像 + 天数」纵向排列

```html
<!-- 左栏：头像（点击编辑）+ 未跟进天数 -->
<div class="flex flex-col items-center gap-0.5 flex-shrink-0">
  <div class="w-10 h-10 md:w-12 md:h-12 rounded-[4px] cursor-pointer overflow-hidden"
       data-no-dbl-copy @click="openEdit(c)" title="点击编辑客户">…头像…</div>
  <span v-if="idleMap[c.id]"
        :class="['text-[10px] leading-none font-medium px-1 py-0.5 rounded whitespace-nowrap', idleClass(idleMap[c.id].days)]"

</div>
```

- 头像的 `data-no-dbl-copy` / `@click="openEdit"` 行为保持不变，只是外层多包了一层纵向 flex 容器。
- 天数使用 10px 字号 + 背景色块，位于头像正下方（实测居中且不超出头像宽度）。

### 2. 脚本：新增天数计算与配色

```js
import { ref, reactive, computed, onMounted, onUnmounted } from 'vue'   // 新增 computed

/** 计算单个客户的未跟进天数，无可用时间返回 null */
function calcIdle(c) {
  const byFollow = !!c?.lastFollowUpTime
  const base = c?.lastFollowUpTime || c?.createdAt
  if (!base) return null
  // 兼容 "2026-09-27 23:04:00"（部分环境 iOS 无法解析空格格式）
  const t = new Date(String(base).replace(' ', 'T')).getTime()
  if (Number.isNaN(t)) return null
  const days = Math.max(0, Math.floor((Date.now() - t) / 86400000))
  return { days, title: `未跟进 ${days} 天（距${byFollow ? '最后跟进' : '创建'} ${fmtDate(base)}）` }
}

/** 3 天内绿 / 4-7 天橙 / 7 天以上红 */
function idleClass(days) {
  if (days <= 3) return 'text-green-600 bg-green-50'
  if (days <= 7) return 'text-orange-600 bg-orange-50'
  return 'text-red-600 bg-red-50'
}
```

要点：

- **取数优先级**：`lastFollowUpTime`（列表接口已由后端 `fillLastFollowUp()` 填充）→ 无则 `createdAt`；两者都没有则不显示。
- **自动刷新**：`idleMap` 是基于 `list` 的 `computed`，此前实现的「新增跟进后调用 `syncListLastFollowUp()` 写回列表」会连带让天数立即重新计算（如从「10天」变「0天」），无需刷新页面。
- **性能**：按卡片一次性算好映射，模板通过 `idleMap[c.id]` 取值，避免每个卡片多次重复计算。
- **提示**：鼠标悬浮显示「未跟进 N 天（距最后跟进/创建 YYYY-MM-DD）」，明确天数基准。
- **容错**：非法日期返回 `null`（不渲染徽标）；负数归零（防止时间偏差显示 -1 天）。
- 不涉及后端改动，接口本就返回 `createdAt` 与 `lastFollowUpTime`。
