# 2026-09-27 客户列表：标题后显示「（今日跟进xx个）」

## 需求

`http://localhost:4000/customers` 页面，在「我的客户」标题后面增加「（今日跟进xx个）」。

## 口径定义

「今日跟进 N 个」= **我今天发起过跟进的客户数（按客户去重）**，仅统计我可访问的客户（我本人的 + 被分享给我的）；同一客户今天跟进多次只算 1 个。取值按 `follow_ups.follow_up_time` 判断是否在今天，`follow_up_time` 为空时回退到 `created_at`。

## 后端改动（`backend/src/main/java/com/fang123/controller/UserCustomerController.java`）

新增接口 `GET /api/user/customers/follow-stats`（需登录），返回：

```json
{ "code": 200, "msg": "成功", "data": { "todayCustomerCount": 2, "todayFollowCount": 3 } }
```

- `todayCustomerCount`：今日跟进过的客户数（去重）→ 页面展示用的就是这个值
- `todayFollowCount`：今日跟进记录条数（备用，便于后续扩展"今日跟进N次"）

实现要点：

1. 先取「可访问客户 id」= 我本人的客户 id + 被分享给我的客户 id（与列表接口 `list()` 的口径保持一致），避免统计出列表里看不到的客户；为空时直接返回 0。
2. 按 `user_id = 当前用户` 过滤，因此**同事对同一客户的跟进不会计入我的数字**。
3. 时间条件用嵌套 or：`follow_up_time >= 今日0点 OR (follow_up_time IS NULL AND created_at >= 今日0点)`。

## 前端改动（`web/src/views/Customers.vue`）

### 1. 标题展示

```html
<h1 class="text-lg md:text-xl font-bold text-[var(--color-text-primary)]">我的客户<span
      class="text-xs md:text-sm font-normal text-[var(--color-text-tertiary)]"
      :title="`今天已跟进 ${todayFollowCount} 位客户`">（今日跟进<span
      class="text-[var(--color-primary)] font-semibold">{{ todayFollowCount }}</span>个）</span></h1>
```

- 追加文字跟在「我的客户」后面，字号更小、灰色，数字用主题色加粗，视觉上从属于标题。
- 鼠标悬浮提示「今天已跟进 N 位客户」，避免"个"的歧义。

### 2. 数据获取

```js
const todayFollowCount = ref(0)
async function fetchFollowStats() {
  try {
    const r = await request.get('/user/customers/follow-stats')
    todayFollowCount.value = Number(r?.todayCustomerCount || 0)
  } catch { /* 统计失败不打断主流程 */ }
}
```

- `onMounted` 中与 `fetchData()` 一起调用；
- 抽屉内**新增跟进成功后立即调用**（紧邻 `syncListLastFollowUp`），无需刷新页面数字就会更新；
- 统计接口异常时静默处理，不影响客户列表本身。

## 验证（本地实测）

测试账号 13900005683（客户 X/Y/Z，分别构造今日跟进、今日多次跟进、5 天前跟进）：

| 场景 | 结果 |
|---|---|
| X 今日 1 条 + Y 今日 2 条 + Z 5 天前 1 条 | `{todayCustomerCount: 2, todayFollowCount: 3}` ✅（去重生效） |
| 页面标题 | 显示「我的客户（今日跟进2个）」，数字为主题色，悬浮提示「今天已跟进 2 位客户」✅ |
| 抽屉内给 Z 新增跟进 | 标题即时变为「（今日跟进3个）」，页面未刷新 ✅ |
| 跟进时间为 NULL、创建时间为今天 | 计入今日统计 ✅ |
| 他人（user_id=1）对我客户的跟进 | 不计入我的数字 ✅ |
| 无任何客户的账号 | `{0, 0}`，标题显示「（今日跟进0个）」✅ |
| 客户被分享给我后我跟进 | 计入（`0 → 1`）✅ |
