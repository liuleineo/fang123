# 2026-08-23 土拍地图年份显示改为"年份-月份"

## 改动内容

`web/src/views/TupaiMap.vue`（/tupai-map 土拍地图页面）：

1. 新增 `ym(d)` 辅助函数：从 `dealDate` 提取"年份-月份"（如 `2025-03`），兼容 `2025-03-15` / `20250315` 两种格式
2. **侧边栏列表项**：年份标签从 `2025年` 改为 `2025-03`
3. **地图 label**：地块名后年份从 `（2025年）` 改为 `（2025-03）`
4. **年份筛选下拉**：从按年份改为按月份粒度（`dateOpts` 生成月份、筛选用 `ym()` 匹配）
