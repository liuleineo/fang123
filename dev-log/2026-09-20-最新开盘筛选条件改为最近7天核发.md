# 2026-09-20 「最新开盘」筛选条件调整

## 需求

- 原口径：核发日期 ≥ 今天 且 核发日期 < 今天 + 8 天（未来 7 天即将取证）
- 新口径（用户确认）：**核发日期在最近 7 天内**，即 `今天 - 7 天 ≤ 核发日期 ≤ 今天`

> 说明：用户原始描述"核发日期 ≥ 今天 且 核发日期 + 7 < 今天"逻辑上无交集（结果恒为空），经确认为"最近 7 天内已核发"。

## 改动文件

`backend/src/main/java/com/fang123/controller/LoupanSpotlightController.java`

1. 类注释更新筛选口径说明
2. 常量 `OPENING_WINDOW_DAYS`：`8` → `7`（改为回溯窗口）
3. `openingPermits(LocalDate today)`：

```java
// 旧
.ge(LoupanPresalePermit::getIssueDate, today)
.lt(LoupanPresalePermit::getIssueDate, today.plusDays(OPENING_WINDOW_DAYS))
.orderByAsc(LoupanPresalePermit::getIssueDate)

// 新
.ge(LoupanPresalePermit::getIssueDate, today.minusDays(OPENING_WINDOW_DAYS))
.le(LoupanPresalePermit::getIssueDate, today)
.orderByDesc(LoupanPresalePermit::getIssueDate)
```

排序同步由"核发日期升序"改为"降序"，让最近核发的楼盘排在前面。

「预售公示」条件（公示日期 ≥ 今天 且 公示日期 < 核发日期）未改动；首页按钮、角标数量、列表接口逻辑均复用，无需前端改动。
