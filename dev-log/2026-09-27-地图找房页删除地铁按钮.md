# 2026-09-27 地图找房页（/map）删除「地铁」按钮

## 需求

`http://localhost:4000/map` 右下角图层切换区删除「地铁」按钮，只保留「卫星」。

## 改动文件

### 1. `web/src/views/MapSearch.vue`

**模板**：删除右下角「地铁」按钮（含 `toggleTransit` 绑定、`transitLoading` 禁用态、`showTransit` 高亮态、`TrainFront` 图标、『加载中/地铁』文案），注释由「右下角图层切换：地铁 / 卫星地图」改为「右下角图层切换：卫星地图」。

**脚本**：删除地铁功能全部死代码，避免留下无人维护的密钥依赖代码：

- 图标/依赖导入：`TrainFront`（lucide）、`MessagePlugin`（tdesign，仅地铁流程在用）
- 状态：`transitMarkers`、`showTransit`、`transitLoading`
- 方法：`toggleTransit`、`clearTransit`、`buildTransitMarker`、`searchNearbyStations`、`viewportRadiusMeters`、`distanceMeters`、`loadAMapPlugin`
- 相关注释段落「===== 地铁站图层 =====」及插件按需加载说明

保留：`toggleSatellite`、`addMarkers`、价格回退逻辑、筛选列表等原有功能，均未改动。

### 2. `web/index.html`

删除已无用的 `window._AMapSecurityConfig = { securityJsCode: ... }` 配置块（该配置仅服务于高德服务类接口，此前唯一使用者就是地铁站检索 `AMap.PlaceSearch`），改为一行说明性 HTML 注释：后续若要用 PlaceSearch / 地理编码等服务类接口，需在加载 JS API 前配置控制台的安全密钥，且该值与 key 不同。纯地图展示 + Markers 不需要。

> 背景：该 key 为「Web端(JS API)」类型且已在控制台开启安全密钥校验，导致 `AMap.PlaceSearch` 恒返回 `INVALID_USER_SCODE`（详见 `2026-09-27-地铁站点检索INVALID_USER_SCODE排查.md`）。本次直接移除该功能，问题自然消失。
