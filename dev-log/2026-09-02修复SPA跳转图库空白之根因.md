# 2026-09-02 修复 SPA 跳转楼盘子页面空白（真正根因）

## 问题

从楼盘详情页点击"图库/户型"等按钮（SPA 内路由跳转），目标页 **main 区域空白**（只剩 header/footer）；整页刷新后正常。

## 排查过程（无头浏览器实测复现）

用 playwright-cli 打开页面点击"图库"后快照显示：`<main>` 完全为空（LoupanSubPage 未渲染出来），控制台关键警告：

```
[Vue warn]: Component inside <Transition> renders non-element root node that cannot be animated.
  at <LoupanDetail ...> at <Transition name="fade" mode="out-in">
```

## 真正根因

`WebLayout.vue` 使用 `<transition name="fade" mode="out-in">` 包裹路由组件，而 **`LoupanDetail.vue` 是"多根节点"组件**（模板根部同时存在 `v-if` 主内容、`v-else` loading、以及根级 `t-image-viewer` 三个根）。

`<Transition mode="out-in">` 要求子组件为单根节点。多根组件在卸载过渡时 Vue 无法正确完成动画 → **旧组件卸载动画挂起，新组件（LoupanSubPage）永远不会被挂载** → main 空白。整页刷新不经过 Transition，所以正常。

此前针对"onMounted/组件复用"的修复方向不正确。

## 修复

`WebLayout.vue`：

- **移除 `<transition mode="out-in">`**，直接渲染 `<component :is="Component" :key="route.fullPath" />`
- key 保留：路由切换强制重建组件实例，同时避免组件复用导致数据不刷新

## 验证

- 无头浏览器实测：详情页 SPA 点击"图库"→ 正常渲染"楼盘图库/户型图(1)/实景图(2)"，不再空白
- web 编译通过，dev 已热更新
