# 2026-08-20 学校地图增加卫星地图切换按钮

## 改动内容

`web/src/views/SchoolMap.vue`（/school-map 学校地图页面）：

1. 地图容器右下角新增"卫星/地图"切换按钮（TDesign 风格按钮，白底 + Map/Satellite 图标）
2. 地图初始化时创建卫星图层 `AMap.TileLayer.Satellite` 和道路标注图层 `AMap.TileLayer.RoadNet`（默认不显示）
3. 新增 `showSatellite` ref 和 `toggleSatellite()` 函数：
   - 切换到卫星：`map.add([satelliteLayer, roadNetLayer])`
   - 切回标准地图：`map.remove([satelliteLayer, roadNetLayer])`
4. 按钮状态联动：显示卫星时按钮文字/图标变为"地图"，反之为"卫星"

## 交互效果

学校地图右下角点击"卫星"按钮切换卫星影像（叠加道路标注），再点切回标准地图。

- 已重新编译 web 端（`npm run build`）成功
