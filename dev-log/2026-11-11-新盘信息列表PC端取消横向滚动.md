# 2026-11-11 新盘信息列表 PC 端取消左右滚动

## 需求

`https://hangfang123.com/xinpanlist` 的 PC 端表格出现左右滚动条，要求 PC 端不横向滚动。

## 问题根因

`web/src/views/XinpanList.vue` 中 `.xinpan-table { min-width: 1400px }`，而页面容器 `.section-container` 最大内容宽只有 **1152px**（`max-width: 1200px` - 左右 `padding: 24px`）。表格固定撑到 1400px，必然在卡片内（`overflow-x-auto`）产生横向滚动；10 列 `w-[...]` 建议宽度叠加 padding 后实际超过 1600px。

## 改动（仅 `web/src/views/XinpanList.vue`）

### 1. 布局：改为 `table-layout: fixed` + `<colgroup>` 定宽

- 去掉 `min-width: 1400px`，改 `width: 100%; table-layout: fixed`
- `<th class="w-[xxx]">` 全部移除，改用 `<colgroup>` + 语义类名统一控宽：

| 列 | ≥1280 | 1024–1279 |
| --- | --- | --- |
| 区域 `c-district` | 70 | 60 |
| 楼盘名称 `c-name` | 176 | 140 |
| 板块 `c-plate` | 92 | 86 |
| 开发商品牌 `c-brand` | 118 | 100 |
| 面积段 `c-area` | 88 | 82 |
| 单价 `c-price` | 106 | 100 |
| 总价范围 `c-total` | 110 | 104 |
| 物业费 `c-fee` | 134 | 132 |
| 优点 / 缺点 | 均分剩余（129 / 86） | 同 |

- 单元格 padding 由 `12px 14px` 收紧为 `12px 10px`（首列左 16px、末列右 16px）
- `1024–1279` 断点额外把字号降到 13px、padding 降到 8px，保证窄屏 PC 仍不横向滚动
- `≤1023`（平板/手机）保持 `table-layout: auto; min-width: 980px`，仍可横向滚动，配合原有「← 左右滑动查看完整表格 →」提示

### 2. 长文本处理

- 楼盘名称：`block truncate` + `title`（hover 看全名）
- 板块：`truncate` + `title`
- 开发商品牌：新增 `.cell-brand`，最多两行（`-webkit-line-clamp: 2`）+ `title`，多品牌如「滨江集团/绿城中国/万科」不再被单行截断
- 区域、物业费：`whitespace-nowrap`，避免「余杭区」拆行、「元/㎡·月」单位折行

## 验证

本地 Vite（`--port 4000`）+ Playwright 对 `/api/public/loupans*`、`/api/public/loupan-filters` mock（`{code:200,data:{...}}` 包装，Mock 数据含超长项目名、多品牌、`1000-2000万` 总价、超长优缺点的极端行）后测量：

| 视口 | 页面 scrollWidth | 表格容器溢出 | 内容被截列数 |
| --- | --- | --- | --- |
| 1920 | 1920 | 0 | 0 |
| 1440 | 1440 | 0 | 0 |
| 1280 | 1280 | 0 | 0 |
| 1024 | 1024 | 0 | 0 |
| 768（平板，按设计可滚） | 768 | 278 | - |

- `overflow-x-auto` 容器在 ≥1024 时 `scrollWidth === clientWidth`，无横向滚动条
- 1440 下各列 `scrollWidth - clientWidth` 均为 0，物业费「5.5-6.5元/㎡·月」完整一行
- `npm run build` 通过（13.39s，仅有既存 chunk 体积告警）
