# 2026-08-26 楼盘详情页增加"真实成交"入口

## 需求

在楼盘详情页 `/loupan/:id` 的"楼盘动态"入口后面增加"真实成交"入口，点击进入展示该楼盘真实成交信息，按成交时间倒序。

## 改动内容

### 后端
- `LoupanPublicController.java` 新增公开接口：
  - `GET /api/public/loupans/{encodedId}/real-deals`：按 loupanId 查询真实成交（`deleted=0`），按 `dealDate` 倒序 + `id` 倒序
  - 注入 `RealDealInfoService`

### web 前端
1. `router/index.js`：新增路由 `loupan/:id/real-deal`（name: LoupanRealDeal，指向 LoupanSubPage.vue，标题"真实成交"）
2. `LoupanDetail.vue`：快捷入口按钮区"楼盘动态"后新增"真实成交"按钮（HandCoins 图标），跳转 `/loupan/:id/real-deal`
3. `LoupanSubPage.vue`：新增 `real-deal` 分支渲染成交列表
   - 每条成交：成交日期 + 房号/小区 + 行政区/板块/面积/备注 + 成交价（万，红色加粗）+ 单价（元/㎡）+ 一手买入价（如有）
   - `subType`/`titleMap`/`iconMap` 增加 real-deal，新增 `fetchRealDeals` 调用公开接口
