# 导航改造：用户中心相关入口统一收纳到「我的」下拉菜单

日期：2026-11-21
涉及文件：`web/src/layouts/WebLayout.vue`

## 需求

站点 `hangfang123.com` 顶部导航中，「客户管理」「任务中心」「我的任务」「会员中心」「个人中心」原本平铺在顶栏右侧，视觉噪音较大。本次将其全部收纳进一个「我的」下拉菜单。

## 改动内容

### 1. PC 端：新增「我的」下拉菜单

- 移除顶栏右侧平铺的 5 个入口链接（客户管理 / 任务中心 / 我的任务 / 会员中心 / 个人中心）以及独立的退出登录图标按钮。
- 新增「我的」触发按钮（`User` + `ChevronDown` 图标，展开时箭头旋转 180°、按钮高亮）。
- 下拉面板内容：
  - 客户管理 → `/customers`（`Users` 图标）
  - 任务中心 → `/tasks`（`ListChecks` 图标）
  - 我的任务 → `/my-tasks`（`BadgeCheck` 图标）
  - 会员中心 → `/member`（`Crown` 图标）
  - 个人中心 → `/profile`（`User` 图标）
  - 分隔线 + 退出登录（`LogOut` 图标）
- 当前路由对应的菜单项高亮（`isMenuActive`：全等或子路径匹配，避免 `/tasks` 与 `/my-tasks` 误判）。
- 菜单项数据抽为 `userMenuItems` 数组，PC 与移动端共用，避免文案/路由两处维护不一致。

### 2. 交互细节

- 点击「我的」切换展开状态；「我的」按钮本身位于 `userMenuRef` 内，不会被点击外部关闭逻辑误关。
- 点击页面空白处关闭（`document` 点击监听，判断 `userMenuRef.contains`）。
- 按 `Esc` 关闭。
- 路由变化后自动关闭（复用已有路由 `watch`，同时关闭 PC 下拉与移动端菜单）。
- 菜单项点击后立即关闭。
- 新增 `user-dropdown` 过渡动画（淡入 + 6px 位移，`<style scoped>`）。

### 3. 移动端：改为折叠分组

- 移动端菜单中原本平铺的 5 个入口，改为「我的」可折叠分组（默认收起，箭头随状态旋转）。
- 展开后子项缩进展示（左侧竖线 + 内边距），结构上与顶部导航区分层级。
- 未登录状态下移动端仍只展示「登录 / 注册」，与改造前一致。

### 4. 保持不变的逻辑

- 登录态判断仍基于 `localStorage.token`。
- 退出登录逻辑 `handleLogout` 未改动（清除 token → 提示 → 回首页）。
- 路由与权限（`requiresAuth`）未改动，仅调整入口展示位置。

## 验证

- `npx vite build` 构建通过（exit 0，仅有既有的 chunk 体积告警）。
- `read_lints` 无诊断。
- 浏览器实测（本地 4000 端口 dev server + 注入 token）：
  - PC 端顶栏不再出现 5 个平铺入口，仅剩「我的」按钮。
  - 点击「我的」展开，菜单含 5 个入口 + 退出登录，链接 `href` 与路由一一对应。
  - 点击「会员中心」跳转 `/member` 且菜单自动收起。
  - 点击空白处菜单收起（菜单链接计数 1 → 0）。
  - 390×844 移动端视口：移动菜单中「我的」默认收起（子项 0 个），点击后展开出全部 5 个子项。

## 备注

实测时使用伪造 token，后端接口返回 401 导致页面出现「服务器错误」提示并最终被跳转到登录页，属测试环境限制，与本次导航改动无关。
