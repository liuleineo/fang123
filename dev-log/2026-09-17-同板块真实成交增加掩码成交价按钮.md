# 同板块真实成交新增「掩码成交价」按钮

日期：2026-09-17
页面：`/loupan/:id/real-deal`（楼盘真实成交子页）

## 需求

在「同板块真实成交」栏标题右侧增加按钮「掩码成交价」：
- 点击后隐藏**成交单价**的具体数值
- 「成交总价(万)」的**后两位用 xx 代替**

再点一次恢复显示。

## 改动

文件：`web/src/views/LoupanSubPage.vue`（仅前端，无接口改动）

### 1. 按钮

「同板块真实成交」标题行右侧（`ml-auto`）新增 `t-button`，仅有数据（`plateDeals.length`）时显示：

- 未掩码：`outline` 样式 + `EyeOff` 图标，文案「掩码成交价」
- 已掩码：`primary` 实心样式 + `Eye` 图标，文案「显示成交价」
- 状态：`maskDealPrice = ref(false)`，点击切换

### 2. 掩码规则

- 成交单价：掩码时统一显示 `****`（无数据仍为 `-`）
- 成交总价(万)：取整数部分字符串，末两位替换为 `xx`
  - `125` → `1xx`
  - `1250` → `12xx`
  - `88`（≤2 位）→ `xx`
  - `null` → `-`
- 未掩码时展示逻辑与改动前完全一致（单价 = 总价×10000÷面积，取整 + 元/㎡）

### 3. 实现

- 新增 `plateUnitPrice(r)` / `plateTotalPrice(r)` 两个渲染函数，替换表格中原有的内联表达式
- 图标新增导入：`Eye, EyeOff`（lucide-vue-next）

## 影响范围

- 「同板块真实成交」表格的成交单价、成交总价两列
- 本小区「真实成交」表格、成交均价走势图、一手买入价列均不受影响
- 掩码为前端视觉开关，不改变接口返回数据；刷新页面后恢复默认（不掩码）

前端需重新构建部署生效。
