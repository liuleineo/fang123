# 2026-08-18 导入商品房预售信息CSV到 loupan_presale_permit 表

## 需求

将 `govdata/一房一价/商品房预售信息20260817.csv`（27287 行）导入本机数据库 `loupan_presale_permit` 表。

## 字段映射

| CSV 列 | 数据库字段 |
|--------|-----------|
| 预售项目名称 | project_name |
| 预售证编号 | permit_no |
| 开发企业 | develop_company |
| 预售证编号STR | permit_no_str |
| 预售总面积 | online_sale_area（顺带导入） |

## 实现

新增脚本 `govdata/一房一价/import_presale.py`：
- 使用 pymysql 连接本机数据库导入
- 按 `permit_no_str` 唯一索引用 `INSERT ... ON DUPLICATE KEY UPDATE` 去重更新
- 空值兜底：`permit_no_str` 为空用 `permit_no`；两者都空生成 `N/A-序号` 占位
- 空项目名/列数不足行跳过

## 结果

- 总处理 26463 行
- 新增插入 26461，更新已有 2
- 跳过 824（空项目名/列数不足）
- 导入后表内共 26463 条
