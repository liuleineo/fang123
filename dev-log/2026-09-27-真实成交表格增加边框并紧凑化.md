# 2026-09-27 真实成交表格：增加网格边框并紧凑化

## 需求

`/loupan/:id/real-deal` 页面「真实成交」数据表需要显示表格边框（与「同板块真实成交」在"掩码成交价"状态下的 Excel 风格网格线一致），同时让单元格内容更紧凑。

## 改动文件

`web/src/views/LoupanSubPage.vue`

### 1. 表格加上网格线类

```html
<!-- 改动前 -->
<table class="w-full text-sm border-collapse">
<!-- 改动后 -->
<table class="w-full text-[13px] border-collapse deal-grid">
```

### 2. 单元格紧凑化（th/td 统一）

| 项 | 改动前 | 改动后 |
| --- | --- | --- |
| 内边距 | `p-3`（12px 四边） | `px-2.5 py-1.5`（10px / 6px） |
| 字号 | `text-sm`（14px） | `text-[13px]` |
| 行分隔线 | `border-t border-gray-100`（行） | 由网格线统一提供，已移除 |
| 数字列 | 无 | 增加 `tabular-nums`，等宽对齐更整齐 |

表头行 `bg-gray-50` 保留，与网格线样式叠加后与掩码状态一致。

### 3. 样式复用（scoped style）

`.deal-grid` 与既有 `.plate-grid` 合并定义，避免重复：

```css
/* Excel 风格网格线：
   .deal-grid  真实成交表格（常驻）
   .plate-grid 同板块真实成交表格（掩码成交价模式）
   注意：项目关闭了 Tailwind preflight，border-style 初始值为 none，
   因此这里必须使用 border 简写显式声明 line-style，仅靠 border-width 不会显示边框。 */
.plate-grid th, .plate-grid td,
.deal-grid th,  .deal-grid td {
  border: 1px solid #dcdcdc;
  vertical-align: middle;
}
.plate-grid th, .deal-grid th {
  background-color: #f5f5f5;
}
```
