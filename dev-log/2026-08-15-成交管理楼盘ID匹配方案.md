# 2026-08-15 成交管理楼盘ID匹配 loupan 表方案

## 需求

admin `/real-deals` 成交信息录入/编辑时，楼盘ID（loupanId）需要匹配 `loupan` 表的 id，方便管理员核对，避免手输错误 id。

## 方案

### 后端

`LoupanController.java` 新增接口：
```
GET /api/admin/loupans/options
参数: keyword (可选)
返回: [{ id, projectName, district }, ...]
```
返回所有楼盘的下拉选项（id + 楼盘名 + 行政区），供成交记录等模块选择匹配。

### 前端

`admin/src/views/RealDealManage.vue`：
1. 新增 `loupanOpts` 下拉选项 + `loupanMap`（id → 楼盘名映射），`onMounted` 时调用 `fetchLoupanOpts()` 加载 `/admin/loupans/options`
2. **编辑/新建成交表单**："楼盘ID"字段由 `t-input-number` 改为 `t-select`（filterable 可搜索），选项显示 `id · 楼盘名（行政区）`
3. **AI 解析表单**："楼盘ID"同样改为下拉选择
4. **列表表格**："楼盘ID"列加宽（160px），两行展示：第一行蓝色 id，第二行灰字楼盘名（未匹配则显示"未匹配到楼盘"）
5. **搜索区**："按楼盘筛选"改为下拉选择（复用 loupanOpts）

## 效果

管理员录入/编辑成交时可直接从下拉选择楼盘，看到楼盘 id 和名称对应关系，方便核对是否匹配正确。
