# 2026-09-27 地图找房页（/map）「公共交通」按钮改为「地铁」

## 需求

右下角图层按钮由「公共交通」（公交站 + 地铁站）收敛为「地铁」（仅地铁站）。

## 改动文件

`web/src/views/MapSearch.vue`（单文件，共 6 处）

| 位置 | 前 | 后 |
| --- | --- | --- |
| 模板按钮文案 | `公共交通` | `地铁` |
| 模板按钮图标 | `<Bus />` | `<TrainFront />` |
| 图标引入 | `Bus` from `lucide-vue-next` | `TrainFront` |
| 图层检索 | `PlaceSearch('公交站')` + `PlaceSearch('地铁站')` 并发两次请求 | 仅 `PlaceSearch('地铁站')` 一次请求 |
| 标记配色 | 公交站 `#0052D9` + 地铁站 `#E34D59` | 统一地铁站 `#E34D59` |
| 提示文案 | 「已显示公共交通：公交站 x 个、地铁站 y 个」 | 「已显示地铁站 x 个」 |

其他同步调整：失败/空结果/异常提示统一为地铁语义（如「地铁站点检索失败」「当前视野未检索到地铁站」「地铁站图层加载失败」），模板与逻辑注释中的「公共交通 / 公交站」字样全部清理（全文件已无「公交」匹配）。

未改动：`transit*` 变量名（`transitMarkers` / `showTransit` / `transitLoading`）保留，语义上仍代表「轨道交通图层」；`toggleTransit` 开/关切换、视野半径换算、插件按需加载逻辑不变。

## 验证

- `search_content` 检索 `公交|Bus|公共交通` → 0 命中
- `read_lints` → 0 报错；`npm run build` → 成功（7.64 s）
- 浏览器实测（`http://localhost:4000/map`）：按钮渲染为「地铁 | 卫星」；点击后弹出「地铁站点检索失败：高德安全密钥（securityJsCode）未正确配置」

## 已知阻塞（未变）

高德 key 的搜索服务仍不可用（`INVALID_USER_SCODE`），需在高德控制台复制「安全密钥 jscode」替换 `web/index.html` 第 10 行的 `securityJsCode`（当前误填为 key 本身）后方能真正检索出地铁站。详见 `dev-log/2026-09-27-地图找房页面新增公共交通切换按钮.md`。
