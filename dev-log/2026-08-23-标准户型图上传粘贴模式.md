# 2026-08-23 标准户型图改为和户型图一样的上传/粘贴模式

## 改动内容

`admin/src/views/LoupanHuxingManage.vue`（/admin/huxings 户型管理）：

"标准户型图"从普通输入框改为和"户型图"一样的 `t-tabs`（上传图片 + 粘贴图片）模式。

### 模板
- "标准户型图" form-item 改为 tabs：
  - 上传图片 tab：`t-upload`（`standardFiles`，`uploadStandardImage`）
  - 粘贴图片 tab：虚线区域 Ctrl+V 粘贴 + 缩略图预览 + "上传并填入URL"按钮（`standardPasteFiles`）
  - 下方保留 URL 输入框（上传/粘贴后自动填入）

### script
- 新增 state：`standardFiles`、`standardPasteFiles`、`standardPasteUploading`
- 新增处理函数：`uploadStandardImage`、`onStandardSuccess/Fail/Remove`、`onStandardPaste`、`uploadStandardPaste`
- `openCreate`/`openEdit` 重置 standard 相关 state
