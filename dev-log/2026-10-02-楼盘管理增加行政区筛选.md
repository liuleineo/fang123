# 2026-10-02 楼盘管理（/admin/loupans）增加行政区筛选

## 需求

管理端「楼盘管理」列表筛选栏增加「行政区」筛选，可快速只看某个区的楼盘。

## 后端改动（`backend/src/main/java/com/fang123/controller/LoupanController.java`）

### 1. 列表接口支持行政区精确筛选

`GET /api/admin/loupans` 新增参数 `district`（可选）：

```java
if (StringUtils.hasText(district)) {
    w.eq(Loupan::getDistrict, district);
}
```

同时**修复了一个潜在 SQL 优先级 bug**：原有 keyword 条件写成 `w.like(A).or().like(B)...`，追加 `AND district = ?` 后会生成
`name LIKE ? OR district LIKE ? OR ... OR land_no LIKE ? AND district = ?`，AND 优先级高于 OR，导致行政区条件对前面几个 OR 分支失效。现改为用 `w.and(wr -> ...)` 把关键词整块包起来：

```java
if (StringUtils.hasText(keyword)) {
    w.and(wr -> wr.like(Loupan::getProjectName, keyword)
            .or().like(Loupan::getDistrict, keyword)
            .or().like(Loupan::getPlate, keyword)
            .or().like(Loupan::getProjectCompany, keyword)
            .or().like(Loupan::getLandNo, keyword));
}
```

### 2. 新增行政区下拉选项接口

`GET /api/admin/loupans/districts` → `["上城区","西湖区", ...]`

- 只取 `loupan.district` 字段，过滤空值/空白，去重后升序；
- 走 MyBatis-Plus 逻辑删除过滤，已删除楼盘不入选项；
- 路径为静态段，与 `/api/admin/loupans/{id}` 不冲突。

## 前端改动（`admin/src/views/LoupanManage.vue`）

### 1. 筛选栏新增下拉

```html
<t-select v-model="district" :options="districtOptions" placeholder="行政区" clearable filterable
  class="w-[150px]" :loading="districtLoading" @change="search" />
```

- 放在关键词输入框与「搜索」按钮之间；
- `clearable`：悬停出现 × 一键清空；`filterable`：可直接输入「西」过滤选项；
- `@change` 直接触发 `search()`（回到第 1 页并重新查询）。

### 2. 脚本

```js
const district = ref('')
const districtOptions = ref([])
const districtLoading = ref(false)

async function fetchData() {
  const p = { page: pg.current, size: pg.pageSize }
  if (keyword.value) p.keyword = keyword.value
  if (district.value) p.district = district.value   // 新增
  ...
}
function resetFilters(){ keyword.value=''; district.value=''; search() }   // 「重置」改为清空全部条件
async function loadDistrictOptions() {
  districtLoading.value = true
  try {
    const list = await request.get('/admin/loupans/districts') || []
    districtOptions.value = list.map(d => ({ label: d, value: d }))
  } catch (e) { districtOptions.value = [] } finally { districtLoading.value = false }
}
onMounted(() => { fetchData(); loadDistrictOptions() })
```

- 「重置」按钮由原来的 `keyword='';search()` 改为调用 `resetFilters()`，同时清空行政区；
- 新建/编辑保存成功后、删除成功后都会调用 `loadDistrictOptions()`，保证下拉里始终是新数据（新填的行政区立即可选）。
