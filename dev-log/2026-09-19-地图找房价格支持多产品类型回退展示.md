# 地图找房价格支持多产品类型回退展示

日期：2026-09-19
页面：`https://hangfang123.com/map`
文件：
- `web/src/views/MapSearch.vue`
- `backend/src/main/java/com/fang123/controller/LoupanPublicController.java`

## 需求

楼盘类型不同价格不同（高层 / 洋房 / 叠墅 / 排屋各自有均价字段，见 `schema.sql:366-369`）。地图找房页面展示楼盘价格时，如果"高层均价（`avg_unit_price`）"为空，应回退展示其他类型价格，而不是显示"价格待定"。

## 问题定位

1. `/map` 页面的列表与地图 marker 价格只取 `avgUnitPrice`，为空时直接显示"价格待定"。
2. 后端 `/api/public/loupans?light=true` 精简模式只 `select` 了 `avgUnitPrice`，洋房/叠墅/排屋三个均价字段根本没返回，前端即使想回退也拿不到数据。

## 实现

### 1. 后端：精简模式补充价格字段

`LoupanPublicController.list` 的 light 分支 select 列表新增：

```java
Loupan::getAvgUnitPriceYangfang, Loupan::getAvgUnitPriceDieshu, Loupan::getAvgUnitPricePaiwu,
```

保留精简模式初衷（仍只返回地图/列表需要的字段），仅多带 3 个价格列。

### 2. 前端：统一价格回退逻辑

`MapSearch.vue` 新增候选顺序与取价函数：

```js
const PRICE_KEYS = [
  { key: 'avgUnitPrice', label: '' },
  { key: 'avgUnitPriceYangfang', label: '洋房' },
  { key: 'avgUnitPriceDieshu', label: '叠墅' },
  { key: 'avgUnitPricePaiwu', label: '排屋' }
]
function pickPrice(lp) { /* 依次取第一个 > 0 的价格，返回 { value, label } */ }
```

- 数据加载时预计算，避免模板和 marker 重复取数：

```js
loupanList.value = (r?.records || []).map(lp => {
  const p = pickPrice(lp)
  return { ...lp, _price: p ? p.value : null, _priceLabel: p ? p.label : '' }
})
```

- 列表项价格：`v-if="lp._price"`，来源非高层时前置类型标签（如 `洋房15000元/㎡`），高层时保持原样 `15000元/㎡`。
- 地图 marker 价格：由 `lp._price` 生成 `${类型前缀}${万元/㎡}`，例如 `洋房1.5万/㎡`；四种价格全空时才显示"价格待定"。

## 说明

- 回退优先级：高层 → 洋房 → 叠墅 → 排屋（高层为楼盘主推产品，其余按价格体量递增顺序兜底）。
- 仅判定 `> 0` 的有效价格，`null` / `0` / 空字符串都会被跳过。
- 未改动 `/loupan/:id` 详情页（其接口非精简模式，字段完整，且已有独立的分类价展示）。
