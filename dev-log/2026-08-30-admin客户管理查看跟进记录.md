# 2026-08-30 admin 客户管理"查看跟进"功能

## 需求

`http://localhost:3002/admin/customers` 客户管理列表操作栏增加"查看跟进"按钮，点击弹窗展示该客户的跟进记录。

## 改动

### 后端（CustomerController.java）

- 新增 `GET /api/admin/customers/{id}/follow-ups` 接口：查询该客户跟进记录（按跟进时间倒序），并填充操作人昵称（`userNickname`）

### 前端（admin/src/views/CustomerManage.vue）

- 操作栏在"编辑"前新增"查看跟进"按钮
- 新增跟进记录弹窗：逐条展示方式标签、操作人、跟进时间、内容、跟进图片（支持点击全屏预览）
- 新增 `openFollows` / `parsePhotos` / `previewImages` / `fmtTime` 方法及 `t-image-viewer` 预览
