# 2026-10-19 客户信息流：资料弹窗支持修改客户头像

## 需求

在客户信息流（`/customer-feed`）点击头像打开的「修改客户资料」弹窗里，除了姓名/手机号/意向/备注，头像本身也要能换。

## 实现（前端 `web/src/views/CustomerFeed.vue`）

**弹窗顶部新增头像区**（放在姓名行之前）：

- 左侧 64×64 头像预览，点击即唤起本地选图（右下角相机角标提示可点）。
- 右侧虚线框上传位（`Image` 图标 +「点击上传，或 Ctrl+V 粘贴」），点击同样唤起选图。
- 上传中：预览图上盖一层半透明遮罩 + `t-loading`，虚线框置灰不可点。
- 已有头像时显示「清除」，清空后保存即移除头像（`photo: ''`）。

**两种上传方式**（按项目要求）：
1. 点击上传：隐藏的 `<input type="file" accept="image/*">`，`@change` 后立刻清空 input，保证重复选同一张图也能触发。
2. 粘贴上传：`onMounted` 时挂 `document` 级 `paste` 监听，`onUnmounted` 移除。
   - 仅在资料弹窗打开（`editVisible`）时生效；
   - 只挑 `clipboardData.items` 里 `kind === 'file' && type.startsWith('image/')` 的项，取到图片才 `preventDefault()`，所以在输入框里粘贴文本不受影响。

**上传接口**：`POST /user/upload/avatar`（`FormData` 字段名 `file`，返回 COS 绝对 URL），
复用的现有接口，自带图片类型白名单 + 5MB 限制，前端同样先做 `type`/`size` 校验并给出中文提示。

**保存**：`PUT /user/customers/{id}`，payload 增加 `photo`，保存成功后仍然只回填本次编辑的字段
（`Object.assign(c, payload)`），列表头像即时更新。

**健壮性**：头像 `<img>` 加 `:key="photo"`，URL 变化时重建元素，避免上一次加载失败设置的
`display:none` 把新头像也一起藏掉（信息流卡片上的头像同样加了 `:key`）。

## 交互说明

- 选图/粘贴后是「先上传、后保存」：上传成功提示「头像已更新，点击保存生效」，点保存才写库，避免误操作直接改掉客户资料。
- 点上传区不会冒泡到信息流的滑动切屏逻辑，弹窗内操作不影响手势。

## 构建

`cd web && npm run build` 已通过，产物 `web/dist` 已更新，刷新 `/customer-feed` 即可验证。
