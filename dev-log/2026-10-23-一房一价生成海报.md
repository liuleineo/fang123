# 2026-10-23 一房一价页面：右下角「生成海报」导出表格图片

## 需求

`/loupan/:id/yfyj` 页面右下角增加「生成海报」按钮，点击后把当前一房一价的表格输出为图片，图片标题需包含**小区名字**和**楼栋号**。

## 实现（`web/src/views/LoupanSubPage.vue`）

### 1. 入口

右下角固定悬浮按钮 `.poster-fab`（只有 `yfyj` 且有数据时渲染）：

- `position: fixed; right: 16px; bottom: calc(24px + env(safe-area-inset-bottom))`，避开 iPhone 底部安全区
- 蓝色渐变胶囊 + `Image` 图标，`z-index: 40`（低于顶部导航 `z-50`）
- 点击 `openPoster()`：先打开弹窗显示 loading，`setTimeout 30ms` 后再同步绘制，避免点击后界面无反馈

### 2. 海报生成方式：Canvas 手绘，不引入截图库

没有用 html2canvas，而是直接从 `yfyjUnits / yfyjAllFloors / yfyjUnitGrid` 这些已有结构画：

- **标题区**（蓝色渐变带 148px）：
  - 主标题 = `loupan.projectName`（小区名），36px 粗体，超长用 `…` 截断，避免压到右上角日期
  - 副标题 = `{楼栋号}号楼 · 一房一价`
  - 右上角：生成日期 + `杭房一二三 · hangfang123.com`
- **表格**：楼层列 64px + 每列 132px × 96px，列头两行（`X单元` / `Y室`），与页面表格一致
  - 单元格内容：房号（粗体）、面积、备案单价、备案总价（元→万，保留 2 位）、房态文字
  - 房态配色复用页面口径：未售灰 / 认购橙 / 已售红 / 抵押紫 / 保留蓝；空格画浅灰 `-`
- **图例**：五种房态色块 + 右侧「X号楼 · 共 N 套」
- **页脚**：数据来源、免责声明「以售楼处公示及网签备案价为准」、生成时间

### 3. 关键细节

- **画布倍率自适应**：默认 2 倍（retina 清晰度），按 `W*H*scale² ≤ 1200 万像素` 逐级降档——iOS Safari 单个画布上限约 1670 万像素，超过会直接得到空白图
- 文字统一 `textBaseline='middle'`，单元格多行按行高总和垂直居中；圆角用 `arcTo` 自绘，不依赖 `ctx.roundRect`（旧版 Safari 没有）
- 导出 PNG（`toDataURL`），文字不糊；弹窗内等比预览（`max-height:60vh`），提示「手机端长按图片保存到相册」
- 「保存图片」用 `<a download>`，文件名：`小区名-楼栋号-一房一价-日期.png`
- 关闭弹窗 300ms 后清空 `posterUrl`，释放几 MB 的 dataURL 内存
