# 土拍地图增加鼠标右键菜单：复制当前坐标

日期：2026-09-17
页面：`https://hangfang123.com/tupai-map`
文件：`web/src/views/TupaiMap.vue`

## 需求

在地图上右键时弹出菜单，可选择"复制当前坐标"，把右键点击位置的经纬度复制到剪贴板。

## 实现

### 1. 模板

- 地图容器 `#amap-container` 增加 `@contextmenu.prevent`，屏蔽浏览器默认右键菜单。
- 新增自定义右键菜单节点（`v-if="ctxMenu.visible"`，`position: fixed`，跟随鼠标 clientX/clientY）：
  - 顶部一行展示当前坐标文本（6 位小数）。
  - 「复制当前坐标」→ 复制高德 GCJ-02 坐标。
  - 「复制原始坐标（WGS84）」→ 复制转换后的 WGS84 坐标（项目地块数据源为 WGS84，便于回填）。
  - 菜单自身 `@click.stop`、`@contextmenu.prevent.stop`，避免与全局关闭逻辑冲突。

### 2. 脚本

- 新增 `gcj02ToWgs84(lng, lat)`：以已有 `wgs84ToGcj02` 为正向函数做不动点迭代（最多 6 次，误差 < 1e-9 提前退出），把高德坐标反算为 WGS84。
- 新增 `fmtCoord(lng, lat)`：统一输出 `经度, 纬度` 格式，保留 6 位小数（约 0.1 米精度），便于直接粘贴到其他地图或数据库。
- 新增右键菜单状态 `ctxMenu = { visible, x, y, lng, lat }` 及 `showContextMenu / closeContextMenu`；`showContextMenu` 做视口边界收敛，防止菜单溢出屏幕右侧/底部。
- 新增 `onMapRightClick(e)`：取 `e.originEvent` 阻止默认右键行为，从 `e.lnglat` 读取经纬度，定位坐标取 `clientX/clientY`。
- 新增 `copyCoord(type)`：`gcj` 复制当前坐标，`wgs` 复制 WGS84；复用 `@/utils/clipboard` 的 `copyText`（Clipboard API + execCommand 降级），复制后用 `MessagePlugin.success` 提示，失败提示手动复制，最后收起菜单。
- `initMap()` 中注册地图事件：`rightclick` 弹菜单；`click`、`movestart`、`zoomstart` 收起菜单。
- 生命周期：`onMounted` 注册 `window` 的 `click / resize / keydown(Esc)` 关闭菜单；新增 `onUnmounted` 移除监听、清理动画定时器并 `mapInstance.destroy()`，避免内存泄漏。

### 3. 样式

新增 `.map-ctx-menu`、`.map-ctx-menu__coord`、`.map-ctx-menu__item` 样式：白底圆角卡片 + 阴影，坐标行使用等宽数字（`tabular-nums`），菜单项 hover 变主题色。

## 依赖

- `lucide-vue-next`：新增 `Copy` 图标。
- `tdesign-vue-next`：`MessagePlugin` 复制结果提示。
- `@/utils/clipboard`：复用已有 `copyText`。
