# 2026-10-20 前端支持 PWA（可添加到主屏幕）

## 需求

`https://hangfang123.com/customers` 支持 PWA：手机浏览器可「添加到主屏幕」，以独立窗口（无地址栏）运行，具备自己的图标和启动页。

## 改动

### 1. `web/public/manifest.json`（新增）

- `name`：杭房一二三 - 找到你的理想家园；`short_name`：杭房一二三
- `start_url`：`/customers`（安装后直接进客户列表；未登录会被路由守卫带到 `/login`）
- `scope`：`/`，`display`：`standalone`，`orientation`：`portrait`
- `theme_color` `#0052D9`（与 global.css 的 `--color-primary` 一致）、`background_color` `#ffffff`
- 图标：192 / 512（`any`）+ 512（`maskable`），两个快捷方式：客户信息流 `/customer-feed`、我的客户 `/customers`
- 用 `.json` 而不是 `.webmanifest`：宝塔默认 nginx 的 mime.types 对 `.webmanifest` 可能返回 octet-stream，`.json` 稳定是 `application/json`，Chrome 可正常解析

### 2. `web/public/sw.js`（新增 Service Worker）

- **页面导航**：network-first，成功即把首页写进 `PAGE_CACHE[index.html]`；断网回退到缓存外壳，连外壳都没有时返回内置的「当前网络不可用」提示页
- **静态资源**（script/style/image/font，同源）：stale-while-revalidate。带 hash 的产物内容不变，不存在脏读
- **接口 `/api/**` 与跨域资源**（COS 图片、高德地图）一律不拦截、不缓存，避免出现「客户资料改了页面还是旧数据」
- 安装时预缓存图标 + 预取 `/index.html` 外壳，装完即可离线打开
- 生命周期：`skipWaiting` + `clients.claim`，`activate` 时清掉旧版本缓存（`CACHE_VERSION` 改动即整体更新）
- 缓存分两个：`fang123-static-<版本>`、`fang123-page-<版本>`，当前 `CACHE_VERSION = v2`

### 3. `web/src/main.js`

生产环境（`import.meta.env.PROD`）才注册 SW，`load` 后 `register('/sw.js', { scope: '/' })`，失败只告警不阻断。
开发环境不注册，避免 Service Worker 干扰 Vite HMR / 改完代码看到旧页面。

### 4. `web/index.html`

- `<link rel="manifest" href="/manifest.json" />`
- `theme-color`、`application-name`、`mobile-web-app-capable`
- iOS：`apple-mobile-web-app-capable` / `status-bar-style=default` / `apple-mobile-web-app-title` + `apple-touch-icon`（180×180）
- favicon 原来指向不存在的 `/favicon.svg`（一直 404），改为 `favicon-32.png` / `favicon-16.png`
- 静态 title / description 从 `fang123` 统一为「杭房一二三」，和 manifest 的名称对齐

### 5. 图标资源（`web/public/`）

`icon-192.png`、`icon-512.png`、`icon-maskable-512.png`、`apple-touch-icon.png`、`favicon-32.png`、`favicon-16.png`

图标源文件：用户提供的绿色客服图标（800×800，`#00CC00` 底 + 白色电话气泡），
不另外设计，直接用它缩放出各尺寸（PIL + LANCZOS），保证与 `/customers` 页面 favicon 视觉一致。

- `icon-192/512.png`、`apple-touch-icon.png`、`favicon-32/16.png`：整图等比缩放，不透明方图
- `icon-maskable-512.png`：满幅绿色底 + 图形缩到 78% 居中，保证落在 Android 圆形安全区内不被裁切
- `sw.js` 的 `CACHE_VERSION` 同步升到 `v2`，换图标后老用户能重新预缓存

> theme_color 仍沿用站点的 `#0052D9`（与页面 UI 一致），不是图标的绿色。

## 使用说明 / 部署注意

- 必须 HTTPS（hangfang123.com 已满足），`http` 下除 localhost 外浏览器不注册 SW
- nginx 现有配置即可：`sw.js`、`manifest.json` 都在 dist 根目录，`try_files $uri` 直接命中
- 建议给 `sw.js` 加 `Cache-Control: no-cache`（nginx 加一条 location 即可），保证发版后能及时检查更新；不加也能靠浏览器 24h 内自动更新
- 安装方式：Android Chrome 菜单「安装应用 / 添加到主屏幕」；iOS Safari 分享面板「添加到主屏幕」
- 本地验证 PWA 要用 `cd web && npm run preview`（dev server 不注册 SW）
