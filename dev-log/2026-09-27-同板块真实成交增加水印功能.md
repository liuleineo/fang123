# 2026-09-27 同板块真实成交：新增"添加水印"功能

## 需求

`/loupan/:id/real-deal` 页面"同板块真实成交"区块，在"掩码成交价"按钮旁增加"添加水印"按钮；点击弹窗输入水印文字，水印以 **45° 斜向平铺、红色、透明度 35%** 覆盖在成交数据上。

## 改动文件

`web/src/views/LoupanSubPage.vue`

### 1. 按钮（"掩码成交价"右侧）

```html
<t-button v-if="plateDeals.length" size="small" variant="outline"
          :theme="watermarkText ? 'primary' : 'default'"
          @click="openWatermark">
  <Droplet class="w-4 h-4 mr-1" />
  {{ watermarkText ? '修改水印' : '添加水印' }}
</t-button>
```

已生效的水印按钮为高亮态，并显示"修改水印"。

### 2. 水印层

表格容器外包一层 `relative`，水印层绝对定位覆盖表格区域（不含标题行/按钮行）：

```html
<div v-else-if="plateDeals.length" class="relative">
  <div class="overflow-x-auto bg-white rounded-xl border border-gray-100"> ...表格... </div>
  <div v-if="watermarkText" class="pointer-events-none absolute inset-0 z-20 rounded-xl" :style="watermarkStyle"></div>
</div>
```

- `pointer-events-none`：不影响表格滚动与 hover
- 水印层在横向滚动容器**外部**，滚动时水印固定覆盖可视区域

### 3. 水印底图生成（canvas，文字长度自适应）

```js
const WATERMARK_COLOR = 'rgba(255, 0, 0, 0.35)'

function buildWatermarkUrl(text) {
  const fontSize = 18, gap = 70
  const font = `bold ${fontSize}px "PingFang SC", "Microsoft YaHei", -apple-system, sans-serif`
  const probe = document.createElement('canvas').getContext('2d')
  probe.font = font
  // 旋转 45° 后文字外接盒边长 ≈ (文字宽 + 字高) / √2，正方形画布加间距即可完整容纳
  const size = Math.max(160, Math.ceil((probe.measureText(text).width + fontSize) / Math.SQRT2) + gap)
  ...
  ctx.translate(size / 2, size / 2)
  ctx.rotate(-Math.PI / 4)              // 45° 斜向
  ctx.fillStyle = WATERMARK_COLOR       // 红色 35%
  ctx.fillText(text, 0, 0)
  return canvas.toDataURL('image/png')
}
```

按 `devicePixelRatio`（上限 2）放大绘制保证高清；`background-repeat: repeat` 平铺。

### 4. 弹窗

`t-dialog` + `t-input`（最多 30 字，支持回车确认）：

- 输入文字 → 确认 → 应用水印 + 成功提示
- **留空确认 → 移除水印**（便于撤销）
