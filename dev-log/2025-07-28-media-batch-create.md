# 媒体素材 - 新增"批量新建素材"功能

## 功能
在 `/admin/medias` 页面"新建素材"按钮右侧新增"批量新建素材"按钮。

## 交互流程
1. 点击"批量新建素材"→ 弹出对话框
2. 设置通用信息：楼盘ID、素材类型
3. 选择多张图片（最多20张）
4. 点击"批量上传 N 张"
5. 前端逐张压缩（宽2000px, JPG, 0.85质量）→ 上传到COS → 创建素材记录
6. 显示进度 `上传中 3/10...`
7. 完成后提示 `批量创建完成：N/总数 条素材`
