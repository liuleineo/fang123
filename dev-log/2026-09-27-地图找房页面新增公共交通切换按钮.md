# 2026-09-27 地图找房页（/map）新增「公共交通」切换按钮

## 需求

`https://hangfang123.com/map` 地图右下角「卫星」按钮旁，新增「公共交通」切换模式按钮。

## 改动文件

### 1. `web/src/views/MapSearch.vue`

**模板**：原本单个卫星按钮改为右下角按钮组（`flex items-center gap-2`），公共交通在左、卫星在右：

```html
<div class="absolute bottom-6 right-4 z-20 flex items-center gap-2">
  <button @click="toggleTransit" :disabled="transitLoading || !mapReady" ...>
    <Bus class="w-4 h-4" />
    {{ transitLoading ? '加载中' : '公共交通' }}
  </button>
  <button @click="toggleSatellite" ...>{{ showSatellite ? '地图' : '卫星' }}</button>
</div>
```

**脚本**：新增公共交通图层逻辑

| 成员 | 说明 |
| --- | --- |
| `transitMarkers` / `showTransit` / `transitLoading` | 站点标记数组、开关状态、加载状态 |
| `loadAMapPlugin(name)` | 按需异步加载高德插件（`index.html` 仅预置了 `AMap.Marker`） |
| `distanceMeters(...)` / `viewportRadiusMeters(...)` | 视野半径换算（1km ~ 50km，高德周边检索上限） |
| `searchNearbyStations(keyword, center, radius)` | `AMap.PlaceSearch.searchNearBy` 周边检索，返回 `{ pois, error }` |
| `buildTransitMarker(poi, color)` | 站点圆点标记（公交站 `#0052D9`、地铁站 `#E34D59`），`title` 悬浮显示站名 |
| `clearTransit()` / `toggleTransit()` | 关闭/开启图层；开启时按当前视野检索「公交站」「地铁站」各最多 50 条 |

交互：点击开启 → 按钮高亮 + `MessagePlugin.success` 提示公交站/地铁站数量；再次点击关闭并清除标记。楼盘 marker 与站点 marker 分开存储，互不影响 `setFitView`。

### 2. `web/index.html`

为第 10 行的 `_AMapSecurityConfig.securityJsCode` 增加注释，说明该值必须是控制台的「安全密钥 jscode」（与 key 不同）。**未修改其值**。

## 关键发现（阻塞项）

代码完成后做真机验证，发现**当前高德 key 的服务类接口不可用**：

| 验证方式 | 结果 |
| --- | --- |
| 页面内 `AMap.PlaceSearch.searchNearBy` | `status: error`，`INVALID_USER_SCODE` |
| 线上 `https://hangfang123.com/map` 同调用 | 同样 `INVALID_USER_SCODE` |
| 探针页（清空 securityJsCode） | 仍然 `INVALID_USER_SCODE`（key 侧强制校验安全密钥） |
| `restapi.amap.com/v3/place/around`（Web 服务） | `USERKEY_PLAT_NOMATCH`（10009，该 key 未开通 Web 服务平台） |

`web/index.html` 第 10 行的 `securityJsCode` 与第 12 行的 `key` 是同一个值，这是错误的：安全密钥需在高德控制台该 key 的「安全密钥」处单独获取。

**处理**：`toggleTransit` 对失败原因做了区分，命中 `SCODE` 时提示「公共交通检索失败：高德安全密钥（securityJsCode）未正确配置」，而不是笼统报错。

## 验证

- `read_lints` → 0 报错；`npm run build` → 成功（9.88 s）
- 浏览器（agent-browser，`http://localhost:4000/map`）：按钮组渲染为「公共交通 | 卫星」，点击后弹出上述明确错误提示，无 marker 残留
- 临时探针页 `web/public/__amap_probe.html` 已删除

## 待办（用户侧）

在高德控制台（https://console.amap.com/ → 应用管理 → 我的应用 → 该 key → 安全密钥）复制 jscode，替换 `web/index.html` 第 10 行的 `securityJsCode` 值，公共交通站点检索即可生效。若希望完全不依赖高德服务接口，可另议「本地地铁线路数据自绘」方案。
