# 2026-10-30 土拍地图：信息弹窗增加溢价率与楼面价

## 需求

`/tupai-map` 点击地块标记弹出的信息弹窗，增加显示「溢价率」和「楼面价」。

## 改动

### 1. 后端（`backend/src/main/java/com/fang123/dto/TupaiLandPublicVO.java`）

公开接口 `/api/public/tupai-lands` 用的是精简 VO，原本没有这两个字段（实体 `LoupanTupaiLand` 里早就有），补上：

```java
private Integer floorUnitPrice;   // 楼面价（元/㎡）
private BigDecimal premiumRate;   // 溢价率（%）
```

Controller 里是 `BeanUtils.copyProperties(entity, vo)`，同名字段自动带出，无需改查询逻辑。

### 2. 前端（`web/src/views/TupaiMap.vue`）

地图 InfoWindow 内容在 `addMarkers()` 里拼 HTML，在「成交：xxx万」下方增加一行：

- 楼面价：`Number(floorUnitPrice).toLocaleString()` + `元/㎡`，数值用主题蓝加粗
- 溢价率：`Number(premiumRate)` + `%`，数值用红色加粗（与成交价呼应）
- 两者都按 `!= null` 判断，老数据为空时该行整行不渲染，不会出现「楼面价 元/㎡」这种残句
- 用 `flex + flex-wrap + gap` 排版，窄弹窗下自动换行

`mvn -DskipTests compile` 通过；`cd web && npm run build` 通过，`web/dist` 已更新。

> 部署提醒：前端改动随 dist 生效，但**字段是后端新加的**，需要重新打包并重启后端服务才会返回 `floorUnitPrice` / `premiumRate`。
