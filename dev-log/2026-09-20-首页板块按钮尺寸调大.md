# 2026-09-20 首页「预售公示 / 最新开盘」按钮尺寸上调

## 背景

上一步改小后按钮偏小，本次回调为适中的胶囊按钮（仍小于最初的卡片式设计）。

## 改动文件

`web/src/views/Home.vue`（仅模板，逻辑未动）

## 尺寸调整

| 项 | 上一步（偏小） | 本次（适中） |
| --- | --- | --- |
| 容器 | `max-w-sm gap-2.5` | `max-w-md gap-3` |
| 按钮内边距 | `px-3.5 py-1.5` | `px-5 py-2.5` |
| 图标 | `w-4 h-4` 底框 + `w-3 h-3` 图标，`rounded` | `w-6 h-6` 底框 + `w-4 h-4` 图标，`rounded-md` |
| 图标与文字间距 | `gap-1.5` | `gap-2` |
| 文字 | `text-xs font-medium` | `text-sm font-medium` |
| 角标 | `min-w-[16px] h-4 text-[10px]` | `min-w-[18px] h-[18px] text-[11px]` |
| hover | `hover:shadow` | `hover:shadow-md` |

## 结果

按钮高度约 40px，保留圆角胶囊外形、图标底框与右上角数量角标；选中态描边、点击切换与筛选逻辑不变，Vite HMR 自动生效。
