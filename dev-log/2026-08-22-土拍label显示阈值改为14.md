# 2026-08-22 土拍地图 label 显示阈值改为 >14 显示

## 需求澄清

用户要求的是 **label（地块文字）** 的显示条件改为：缩放 >14 显示，<=14 不显示（不是右下角缩放级别数字）。

## 改动内容

`web/src/views/TupaiMap.vue`（/tupai-map 土拍地图页面）：

1. `syncLabelVisibility()`：hide-label 阈值从 `<= 13` 改为 `<= 14`
   - 缩放 `<= 14`：加 `hide-label` class → 隐藏地块文字 label（只显示定位图标）
   - 缩放 `> 14`：移除 `hide-label` → 显示地块名称+年份文字
2. CSS 注释同步更新（<=14）
3. 右下角"级别 xx"缩放数字显示恢复为始终显示（之前误加了 `v-if="currentZoom>14"`，已撤销，那条条件本意是 label 的）
