# 2026-10-18 客户跟进信息流页面

## 需求

用户端「今日跟进进度」弹窗底部在「关闭提示」旁增加「跟进客户」按钮，点击进入新页面：
以信息流方式展示客户资料与跟进记录，上下滑动切换客户；页面底部固定「电话客户」「增加跟进」两个按钮。

## 入口

`web/src/views/Customers.vue` 弹窗底部按钮改为两个：

```
[ 关闭提示 ]  [ 跟进客户 ]   → router.push('/customer-feed')
```

## 新页面 `web/src/views/CustomerFeed.vue`

**路由**：`/customer-feed`，注册在 WebLayout 之外（全屏，避免顶部导航与底部占位干扰）。

**数据**
- `GET /user/customers?sortField=lastFollowUpTime&sortOrder=asc`，每页 20 条
  按「最久未跟进」排序（从未跟进的排最前），打开就是从最该联系的人开始；
- `GET /user/customers/{id}/follow-ups` 按需加载，缓存到 `followCache`，
  每次预加载「当前 + 下一位」，滑动时不出现空白；
- 滑到距末尾 3 个客户时自动预取下一页（无限流）。

**交互**
- 垂直信息流用原生 `scroll-snap-type: y mandatory` + 每屏 `scroll-snap-align: start`，
  触摸滑动/滚轮/上下键都是整屏吸附切换，无需自己算手势；
- 顶部悬浮栏显示 `当前序号 / 总客户数`，左上角返回；
- 滚动用 `requestAnimationFrame` 节流计算当前屏索引，仅切屏时触发预加载。

**每屏内容**
- 客户卡：头像、姓名、意向标签、共享标记、手机号、未跟进天数（≥7 天红色、≥3 天橙色）、需求备注；
- 跟进记录：最近 5 条（方式标签 + 时间 + 内容），超出显示「仅显示最近 5 条，共 N 条」；
  限制条数是为了让每屏内容不溢出，保证上下滑动始终能切换客户；
- 跟进图片：解析 `photos`（JSON 数组字符串，实测格式 `["https://...jpg"]`），
  以 56px 缩略图网格展示在内容下方，点击用 `t-image-viewer` 全屏预览（支持左右切换同一条记录的图片）；
- 底部提示当前可上滑/已到底。

**底部操作（固定）**
- 「电话客户」：统一使用 `tel:` 协议直接调起拨号（`window.location.href = tel:号码`），
  不做"桌面端复制号码"的降级——按使用要求，点击即拨号；号码为空时提示"该客户没有填写手机号"；
- 「增加跟进」：弹窗选择方式（电话/微信/到访/其他）+ 填写内容，提交
  `POST /user/customers/{id}/follow-ups`，成功后刷新该客户记录并同步卡片上的「最后跟进」，
  返回列表页时列表与今日跟进数会重新加载（页面未用 keep-alive，回来即刷新）。
