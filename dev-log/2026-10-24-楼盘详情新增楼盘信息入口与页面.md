# 2026-10-24 楼盘详情：新增「楼盘信息」入口 + 独立页面

## 需求

`/loupan/:id` 详情页的快捷入口行里，在「图库视频」前面增加「楼盘信息」入口，点击进入独立的楼盘信息页面。

## 改动

### 1. 入口按钮（`web/src/views/LoupanDetail.vue`）

入口顺序：**楼盘信息 / 图库视频 / 户型 / 一房一价 / 楼盘动态 / 二手真实成交**，跳转 `/loupan/:id/info`，图标用 `Info`。

同时调整了入口行布局：原来 5 个 `flex-1` 按钮在手机上已被挤压，加到 6 个后「二手真实成交」会被裁字，改成

```html
<div class="grid grid-cols-3 gap-2 ... sm:flex sm:flex-wrap">
  <t-button class="!rounded-xl !h-auto !py-2.5" ...>
```

- 手机：3 列 × 2 行，每个按钮等宽、文字完整
- `sm` 及以上：恢复原来的一行 `flex` 排布（按钮不再 `flex-1` 撑满）

### 2. 新页面 `web/src/views/LoupanInfo.vue` + 路由

路由（`web/src/router/index.js`，放在 media 之前）：

```js
{ path: 'loupan/:id/info', name: 'LoupanInfo', component: () => import('@/views/LoupanInfo.vue'), meta: { title: '楼盘信息' } }
```

页面结构与其他子页面（图库/户型/一房一价）保持一致：
面包屑「楼盘详情 › 楼盘信息」+ 标题区（`Info` 图标 + 楼盘名）+ 内容卡片。
内容数据仍取 `/public/loupans/{id}`，加载中显示 loading，失败/无数据显示「暂无楼盘信息」；
`watch(route.params.id)` 处理 SPA 内切换楼盘时组件复用的问题。

### 3. 抽公共组件 `web/src/components/LoupanInfoBlocks.vue`

详情页原来的「楼盘信息」（基本信息 / 建筑指标 / 开发信息 / 车位信息 / 外立面 / 样板房 / 小区配套）
和「周边配套」（教育 / 交通 / 医疗 / 商业 / 景观）整段搬进组件，详情页与新页面共用：

- props：`loupan`（详情对象）、`showMainTitle`（默认 true，子页面顶部已有大标题时传 false）、`showSupport`（默认 true）
- 详情页改为 `<LoupanInfoBlocks :loupan="loupan" />`，视觉与原来完全一致
- 新页面传 `:show-main-title="false"`，避免出现两个「楼盘信息」标题
- `fmtNum` / `splitItems` 一并迁入组件；详情页里因此不再使用的图标（Shield/Car/Paintbrush/Eye/Sparkles）和函数已清理
