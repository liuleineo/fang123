# 2026-11-07 新盘列表独立成页 + 路由调整（/xinpan、/xinpanlist）

## 需求

- 首页 `#list` 锚点改为独立页面 `/xinpan`
- 原 `/xinpan`（新盘信息表格页）改到 `/xinpanlist`

## 实现

### 1. 抽出公共组件 `web/src/components/LoupanListSection.vue`

把首页「筛选栏 + 楼盘列表 + 分页」整段（含 Loading / 空态 / 板块提示条 / 卡片样式）搬进组件：

- props：`spotlight`（`'' | 'presale' | 'opening'`，与父级 `v-model:spotlight` 双向绑定）、`showKeyword`（筛选栏是否显示关键词搜索框）
- 内部维护：列表数据、行政区/板块/楼盘类型筛选、分页（12 条/页）
- `defineExpose`：`search(keyword)`、`toggleSpotlight(type)`、`clearSpotlight()`、`refresh()`、`total`
- 保留 `id="list"`，旧的 `/#list` 链接仍可跳到列表位置

### 2. 首页 `Home.vue` 瘦身

- 模板只保留 Hero（标题、搜索框、预售公示/最新开盘按钮、热门标签）+ 组件 + 底部 CTA
- Hero 搜索框/热门标签 → `listRef.search(keyword)`
- 板块按钮 → `listRef.toggleSpotlight(type)`，`v-model:spotlight` 让按钮高亮状态与组件同步
- 删掉随列表一起迁走的 8 个状态与 5 个请求函数；`fetchSpotlightCounts`（按钮角标）保留在首页

顺带修掉一个老问题：原来分页 `@change="fetchData"` 会把分页事件对象当成 `showAll` 参数，
导致翻页后丢掉「只看在售」条件；组件里改为固定 `salesStatus=1`。

### 3. 新页面 `web/src/views/Xinpan.vue`

- 页面标题「新盘」+ 副标题，下面直接复用 `<LoupanListSection :show-keyword="true" />`
- 筛选栏里带关键词搜索框，与原首页搜索能力一致

### 4. 路由与导航

```js
{ path: 'xinpan',     name: 'Xinpan',     component: Xinpan.vue,     meta: { title: '新盘' } }
{ path: 'xinpanlist', name: 'XinpanList', component: XinpanList.vue, meta: { title: '新盘信息' } }
```

导航：`新盘 → /xinpan`、`新盘信息 → /xinpanlist`（原来 `新盘 → /#list`、`新盘信息 → /xinpan`）。
