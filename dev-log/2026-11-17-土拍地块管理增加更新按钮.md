# 2026-11-17 土拍地块管理：操作栏增加「更新」按钮

## 需求

`/admin/tupai-lands`（土拍地块管理）操作栏新增「更新」按钮：点击后按该记录的 `resourceId` 从浙江自然资源交易平台重新拉取数据，覆盖数据库中的地块信息。

## 实现

### 1. 后端：`service/TupaiResourceService.java`

把原 `fetchOne()` 里的「拉详情 → 位置示意图 → 坐标 → 计算 → 构建实体」逻辑抽成私有方法 `parseResource(resourceId)`，返回未落库的 `LoupanTupaiLand`，供新增与更新复用。

新增 `refreshByResourceId(String resourceId)`：

```java
public LoupanTupaiLand refreshByResourceId(String resourceId) {
    LoupanTupaiLand existing = tupaiLandService.lambdaQuery()
            .eq(LoupanTupaiLand::getResourceId, resourceId).one();
    if (existing == null) throw new IllegalArgumentException("本地未找到该 resourceId 对应的地块");

    LoupanTupaiLand fresh = parseResource(resourceId);
    // 保留本地维护字段，避免被平台数据清空
    fresh.setId(existing.getId());
    fresh.setLoupanId(existing.getLoupanId());
    fresh.setPlate(existing.getPlate());
    fresh.setSort(existing.getSort());
    fresh.setDeleted(existing.getDeleted());
    tupaiLandService.updateById(fresh);
    return tupaiLandService.getById(existing.getId());
}
```

**保留字段说明**：`parseResource()` 会把 `plate` 置空、`sort` 置 0，且平台数据没有关联楼盘，所以更新时显式回填 `loupanId / plate / sort / deleted`，只覆盖平台业务字段（地块名、编号、区、范围、竞得单位、用地类型、面积、起拍价、成交价、容积率、楼面价、溢价率、成交日期、位置图、经纬度）。

`fetchOne()` 同时优化为**先查重再请求平台**，已存在时不再发起外部调用。

### 2. 后端：`controller/LoupanTupaiLandController.java`

```java
POST /api/admin/tupai-lands/{id}/refresh
```

- 记录不存在 → 404「地块不存在」
- `resourceId` 为空 → 400「该地块没有 resourceId，无法更新」
- 平台异常 → 500「更新失败：{原因}」
- 成功 → 返回 `Result.success("更新成功", 更新后的地块)`

### 3. 管理端：`admin/src/views/LoupanTupaiLandManage.vue`

- 操作栏在「查看地块」与「编辑」之间新增「更新」按钮，仅当 `row.resourceId` 存在时显示
- 按钮带独立 loading（`refreshingId === row.id`），避免整行按钮同时转圈
- `refreshLand(row)`：`POST /admin/tupai-lands/{id}/refresh`，`timeout: 60000`（平台接口含图片与坐标请求，较慢）；成功 `MessagePlugin.success` 后 `fetchData()` 刷新列表，失败展示后端 `msg`
- 操作列宽 170 → 210，容纳新增按钮

## 备注

平台详情接口单条耗时较长（详情 + 文件列表 + 坐标），批量新增时原有 `fetchByResourceIds` 仍保持每条 sleep 1 秒节流；「更新」为单条按需触发，未加节流。
