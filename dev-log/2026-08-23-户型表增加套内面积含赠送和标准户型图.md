# 2026-08-23 loupan_huxing 表增加套内面积含赠送和标准户型图URL字段

## 需求

`loupan_huxing`（楼盘户型表）增加两个字段：
1. `inside_area` 后面增加"套内面积含赠送"
2. `huxing_image` 后面增加"标准户型图URL"

## 改动内容

### 1. schema.sql
- `inside_area` 后新增 `inside_area_with_gift` int 套内面积含赠送㎡
- `huxing_image` 后新增 `standard_huxing_image` varchar(500) 标准户型图URL

### 2. 实体 LoupanHuxing.java
- 新增 `insideAreaWithGift`、`standardHuxingImage` 字段

### 3. admin LoupanHuxingManage.vue
- 表单：套内面积后新增"套内面积含赠送(㎡)"输入框；户型图后新增"标准户型图URL"输入框
- `initForm()` 加两字段初始值
- AI 填入处加 `insideAreaWithGift`

### 4. 本机数据库
ALTER TABLE 为本机 `loupan_huxing` 添加 `inside_area_with_gift`、`standard_huxing_image` 字段（已验证）
