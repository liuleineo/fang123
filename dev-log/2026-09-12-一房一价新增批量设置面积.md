# 一房一价新增「批量设置面积」

日期：2026-09-12
页面：`/admin/yfyj`（一房一价）

## 需求

在「批量设置状态」按钮后面增加「批量设置面积」按钮，按当前筛选条件批量修改房源的建筑面积。

## 改动

### 前端

`admin/src/views/LoupanYfyjManage.vue`

- 工具栏「批量设置状态」右侧新增按钮：
  `<t-button variant="outline" @click="openBatch('area')">批量设置面积</t-button>`
- `batchMeta` 新增：`area: { label: '建筑面积(㎡)', title: '批量设置面积' }`
- 批量设置弹窗中新增面积输入分支：`t-input-number`（`:min="0" :decimalPlaces="2"`，placeholder「输入建筑面积，如 89.5」），并在下方提示「单位：㎡，支持两位小数」
- `doBatchUpdate` 的 `keyMap` 新增 `area: 'setArea'`

### 后端

`backend/src/main/java/com/fang123/controller/LoupanYfyjController.java`

- `POST /api/admin/yfyj/batch-update` 支持 `setArea`：
  - 新增字段判定 `hasArea`，加入「至少指定一个字段」的校验列表
  - `uw.set(LoupanYfyj::getArea, toDecimalOrNull(body.get("setArea")))`
- 新增辅助方法 `toDecimalOrNull(Object)`：解析为 `BigDecimal` 并 `setScale(2, HALF_UP)` 保留两位小数，非法值返回 null

### 接口

```
POST /api/admin/yfyj/batch-update
{
  "loupanId": 123, "buildingNo": "1", "unitNo": "1", "roomNo": "", "permitNo": "",
  "setArea": 89.5
}
→ 返回受影响行数
```

筛选条件与其它批量设置（楼盘ID/户型ID/预售证号/单元/状态）完全一致，前端需重新构建、后端需重新打包并重启服务生效。
