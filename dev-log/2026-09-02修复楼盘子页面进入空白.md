# 2026-09-02 修复楼盘子页面（图库等）SPA 进入空白

## 问题

`/loupan/:id/media`（图库）等子页面，从楼盘详情页点击进入时**打开空白**，浏览器刷新后才显示内容。

## 根因

`LoupanSubPage.vue` 只在 `onMounted` 中按 `subType` 加载数据。该组件被多个路由复用（media/huxing/yfyj/dynamic/real-deal 共用同一组件）：

- **首次挂载**（含刷新）：`onMounted` 触发，数据正常加载
- **SPA 内路由切换**（详情→图库、图库↔户型等）：Vue Router **复用同一组件实例**，`onMounted` 不再触发 → 数据从未加载 → 空白

## 修复

`LoupanSubPage.vue`：

- 移除 `onMounted`，改为 `watch([id, subType], ...)` **`immediate: true`**
  - 首次挂载立即加载（等价原 onMounted）
  - 子页面类型或楼盘 ID 变化时自动重新加载
- `loadCurrent()` 先清空旧列表数据（medias/huxings/yfyjList/dynamics/realDeals/plateDeals 等），避免跨楼盘残留旧内容

## 验证

- web 编译通过；SPA 内从详情页点"图库/户型/一房一价"及各子页互切均会正确触发数据加载
