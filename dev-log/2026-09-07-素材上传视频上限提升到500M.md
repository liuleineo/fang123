# 2026-09-07 素材（视频）上传上限 100MB → 500MB

## 需求

媒体素材支持上传最大 500MB 的视频（如高清航拍、楼盘宣传片）。

## 现状与关键点

后端存在两处 multipart 配置，且 `MultipartConfig.java` 的自定义 `MultipartConfigElement` Bean 优先级高于 yml（Spring Boot `@ConditionalOnMissingBean`），因此**真正生效的是代码 Bean 的 50MB 单文件限制**（三处 yml 此前为 100MB/200MB 并未全部生效）。

## 改动

### 1. 后端（4 处统一为 500MB 单文件 / 600MB 请求体）
- `backend/src/main/java/com/fang123/config/MultipartConfig.java`
  `setMaxFileSize 50MB → 500MB`，`setMaxRequestSize 200MB → 600MB`
- `backend/src/main/resources/application.yml`
  `max-file-size: 500MB`、`max-request-size: 600MB`
- `backend/src/main/resources/application-dev.yml`（同上）
- `backend/src/main/resources/application-prod.yml`（同上）

> 补充（上 500MB 后仍报"单文件不能超过 100M"的遗漏拦截点）：
> - `backend/src/main/java/com/fang123/service/CosService.java` `uploadFile()` 内另有 100MB 硬校验 → 已改为 500MB
> - `backend/src/main/java/com/fang123/common/GlobalExceptionHandler.java` `MaxUploadSizeExceededException` 提示文案 → 500MB

### 2. admin 前端 `admin/src/views/LoupanMediaManage.vue`
- 上传控件 `tips` 文案：100MB → 500MB
- `uploadRequest()` 上传前大小校验：视频 >500MB 直接拦截并提示（不发起请求）
- 视频上传 axios 超时 300s → 1200s（20 分钟，覆盖 500MB 的慢上行场景）；图片仍 120s

### 3. Nginx 配置示例（`README.md`）
`client_max_body_size 600m;` + 新增 `client_body_timeout 600s;` + `proxy_read_timeout 600s;`

## 待办（服务器操作，需用户执行）

部署后，在线上 Nginx（宝塔：网站 → 配置文件）`server {}` 内更新并重载：

```nginx
client_max_body_size 600m;
client_body_timeout 600s;
proxy_read_timeout 600s;
```

否则线上仍会以旧上限（200m）拒绝 500MB 视频（413）。
