# 2026-08-15 成交管理楼盘ID下拉默认按小区名称搜索

## 改动内容

`admin/src/views/RealDealManage.vue`（真实成交管理）：

1. `fetchLoupanOpts(keyword)` 增加关键字参数：有值时请求 `/admin/loupans/options?keyword=xxx`，无值时加载全部
2. 新增 `watch(form.communityName)`：当"小区名称"变化时，自动以该名称作为关键字重新加载楼盘下拉选项，使下拉默认展示匹配该小区的楼盘，方便核对匹配楼盘ID

## 交互效果

- 录入/编辑成交时填写"小区名称"后，楼盘ID下拉自动过滤为匹配该小区的楼盘列表
- 编辑已有记录时，打开表单即按已填小区名加载匹配楼盘
- AI 填入表单时同样生效
- 下拉仍支持手动 filterable 搜索

## 说明

- 已重新编译 admin 端（`npm run build`）成功
- 后端接口 `/admin/loupans/options` 已支持 `keyword` 参数（上一改动已实现）
- 若需线上生效，需将 `admin/dist` 部署到线上服务器
