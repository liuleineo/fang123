# 2026-08-30 web 端客户列表页面

## 需求

web 端增加客户列表页面，展示当前登录用户的客户（姓名/电话/备注），操作按钮：电话/跟进记录/分享；页面右下角增加"录入客户"按钮。

## 改动内容

### 后端（新增6个文件 + 1个Controller）
1. `entity/FollowUp.java` + `entity/CustomerShare.java`：跟进记录、客户分享实体
2. `mapper/FollowUpMapper.java`、`mapper/CustomerShareMapper.java`
3. `service/FollowUpService.java` + Impl、`service/CustomerShareService.java` + Impl
4. `controller/UserCustomerController.java`（`/api/user/customers`，需认证）：
   - `GET /api/user/customers` 当前用户客户列表（本人 + 被分享给我的，分页）
   - `GET /api/user/customers/{id}` 详情（校验访问权）
   - `POST /api/user/customers` 录入客户（归属当前用户）
   - `DELETE /api/user/customers/{id}` 删除（仅本人）
   - `GET /api/user/customers/{id}/follow-ups` 跟进记录列表（填充操作人昵称）
   - `POST /api/user/customers/{id}/follow-ups` 添加跟进
   - `POST /api/user/customers/{id}/share` 分享客户（按对方手机号，写入 customer_shares）
   - `GET /api/user/customers/{id}/shares` 分享列表
   - 通过 `JwtUtil.getUserIdFromToken` 从 token 解析当前用户

### web 前端（新增1个页面 + 2处修改）
1. 新增 `views/Customers.vue`（路由 `/customers`，requiresAuth）：
   - 客户列表卡片：姓名/电话/意向/备注
   - 操作按钮：电话（tel: 拨号）/跟进记录（抽屉：查看+添加跟进）/分享（弹窗输入对方手机号）
   - 右下角悬浮"录入客户"按钮（t-fab），新建客户弹窗（姓名/手机号/意向/备注）
   - 分页加载
2. `router/index.js`：注册 `customers` 路由（name: Customers，标题"我的客户"，requiresAuth）
3. `layouts/WebLayout.vue`：已登录导航增加"客户管理"入口
