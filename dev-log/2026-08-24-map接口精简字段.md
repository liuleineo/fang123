# 2026-08-24 /map 接口改为只请求需要的字段

## 需求

`/map` 地图找房页的 `/api/public/loupans` 请求返回了所有字段，改为只请求需要的字段。

## 改动内容

### 后端 LoupanPublicController.java
`/api/public/loupans` 列表接口新增 `light` 参数：
- `light=true` 时用 `w.select(...)` 只查询地图/列表所需字段：
  id、projectName、coverImage、longitude、latitude、district、plate、houseType、decorateType、avgUnitPrice、areaMin、areaMax、salesStatus、minTotalPrice、maxTotalPrice

### 后端 Loupan.java 实体
- 类加 `@JsonInclude(JsonInclude.Include.NON_NULL)`：null 字段不序列化，进一步减少传输（只返回有值的字段）

### 前端 MapSearch.vue
- `fetchData` 请求 `/public/loupans` 增加 `light: true` 参数

## 效果

`/map` 接口不再返回全部字段，只返回地图标记和列表需要的精简字段，且 null 字段不传输，传输量大幅减少。

## 编译

- web 编译成功
- 后端 jar 编译成功并已重启，已验证 light 接口只返回精简字段

## 说明

- `@JsonInclude(NON_NULL)` 影响所有 Loupan 相关接口（详情也省略 null 字段，前端 v-if 判断不受影响）
- 若需线上生效，需部署 web dist + 后端 jar 并重启后端
