# 2026-09-27 客户列表：新增跟进后同步更新「最后跟进」

## 需求

`/customers` 页面新增跟进记录后，列表卡片上的「最后跟进」信息需要同步更新（此前只刷新了抽屉内的跟进列表，卡片仍显示旧值，必须手动刷新页面才会更新）。

## 改动（`web/src/views/Customers.vue`）

新增本地同步函数，新增跟进成功后将结果直接写回列表当前项，避免整页刷新：

```js
/** 新增跟进后，同步列表中该客户的"最后跟进"展示（无需整页刷新） */
function syncListLastFollowUp(customerId, content, time) {
  const target = list.value.find(x => x.id === customerId)
  if (!target) return
  target.lastFollowUpTime = time || new Date().toISOString()
  target.lastFollowUpContent = content
  // 当前按跟进时间排序时，重新拉取以保持列表顺序正确
  if (sortOption.value !== 'default') fetchData()
}
```

调用点：

1. `addFollowUp()`：提交成功后调用 `syncListLastFollowUp(customerId, content, created.followUpTime)`，时间取接口返回的 `followUpTime`（后端 `FollowUp` 实体时间，未传时后端补 `now`），保证与后续排序/分页数据一致；同时仍刷新抽屉内跟进列表。
2. `recordPhoneCall()`：点击拨打电话自动落一条「拨打了客户电话」跟进，同样调用同步函数，卡片即时显示该跟进。

排序兼容：当列表按「跟进新→旧 / 跟进旧→新」排序时（`sortOption !== 'default'`），本地插入会破坏顺序，此时自动触发 `fetchData()` 重新拉取排序后的数据。

后端无需改动：`GET /api/user/customers` 由 `fillLastFollowUp()` 实时查 `follow_ups` 表最大 `follow_up_time` 填充 `lastFollowUpTime / lastFollowUpContent`。
