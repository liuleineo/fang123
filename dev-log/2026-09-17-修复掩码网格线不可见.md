# 修复：掩码模式下单元格网格线看不到（Tailwind preflight 关闭导致 border 不渲染）

日期：2026-09-17
页面：`/loupan/:id/real-deal`（同板块真实成交）
文件：`web/src/views/LoupanSubPage.vue`（仅前端）

## 现象

点击「掩码成交价」后，表格没有出现预期的 Excel 风格网格线，单元格边框完全看不到。

## 根因（重要）

`web/tailwind.config.js` 中配置了：

```js
corePlugins: { preflight: false }
```

preflight 被关闭后，Tailwind 不再注入 `*,::before,::after { border-width:0; border-style:solid }` 这段重置。
而 Tailwind 的 `border` / `border-gray-300` 等工具类**只设置 `border-width` 与 `border-color`，不设置 `border-style`**。
`border-style` 的初始值是 `none`，因此宽度为 1px 也没有任何可见效果。

验证结果（构建产物）：
- 之前使用的任意变体类已正确生成：`.\[\&_th\]\:border th{border-width:1px}` —— 规则存在但仍不可见，证明问题出在 `border-style`。
- 产物中没有 preflight 的 `border-width:0;border-style:solid` 重置。

> 副作用提示：项目内所有 `border border-gray-*` 的卡片/容器边框目前同样不生效（一直是默认无边框观感）。

## 改动

1. 去掉依赖 Tailwind `border` 工具类的写法，改为在组件内用 `scoped` 样式显式声明边框简写（简写会同时设置 `border-style`）：

```vue
<table class="w-full text-sm border-collapse" :class="{ 'plate-grid': maskDealPrice }">
```

```css
.plate-grid th,
.plate-grid td {
  border: 1px solid #dcdcdc;
  vertical-align: middle;
}
.plate-grid th {
  background-color: #f5f5f5;
}
```

2. 表格容器恢复原有单一 class（`border border-gray-100`），不再做条件切换；外框由网格线自身形成。

## 效果

- 掩码开启：隐藏成交单价列 + 全表出现 1px 灰网格线（Excel 观感），表头底色 `#f5f5f5`
- 掩码关闭：恢复原样式

## 验证

- 无 lint 错误
- `web` 构建成功（11.89s）
- 产物校验：`dist/assets/LoupanSubPage-Djgu4Fdn.css` 含
  `.plate-grid th[data-v-ee7066f2],.plate-grid td[data-v-ee7066f2]{border:1px solid #dcdcdc;vertical-align:middle}`
