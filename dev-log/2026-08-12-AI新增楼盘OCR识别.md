# 2026-08-12 AI新增楼盘（OCR识别）

## 需求背景

在管理端楼盘管理页面"新建楼盘"按钮旁新增"AI新增楼盘"按钮，管理员上传楼盘资料图片（宣传页截图、户型图等），通过腾讯云 OCR 通用印刷体识别提取文字，再用正则规则解析出楼盘结构化字段，自动填入新建楼盘表单，人工核对确认后保存。

## 核心功能

- "AI新增楼盘"按钮：位于"新建楼盘"按钮右侧，带 Sparkles 图标区分
- 上传对话框：支持多张图片拖拽/点击上传，图片预览列表
- OCR 识别：调用腾讯云通用印刷体识别 API 提取文字
- 字段解析：正则规则自动匹配中文楼盘文本，提取结构化字段
- 结果预览：识别出的字段以表格形式展示，用户可逐条确认/修改
- 一键填入：确认后自动填入新建楼盘的 form 表单（5 个 tab 全量填充）

## 技术栈

- 后端：Spring Boot 3.4.1 + Java 21 + Tencent Cloud OCR SDK（tencentcloud-sdk-java-ocr）
- 前端：Vue 3 + TDesign Vue Next + Lucide Icons

## 实现方案

### 整体流程

上传图片 → 后端接收 MultipartFile → Base64 编码图片 → 调用腾讯云 GeneralBasicOCR → 获取识别文本列表 → 正则规则解析字段 → 返回结构化 JSON → 前端展示预览 → 用户确认/修改 → 填入 form 表单保存

### 后端实现

1. pom.xml 添加 `tencentcloud-sdk-java-ocr` 依赖，复用已有 COS 的 SecretId/SecretKey 凭证
2. 新建 `OcrService.java`：注入 COS 凭证，`recognizeText(MultipartFile)` 方法将图片转 Base64，构建 OCR 请求调用 SDK，返回识别文本行列表
3. 新建 `OcrTextParser.java`：通过正则规则匹配中文楼盘文本，解析 projectName / district / avgUnitPrice / areaMin / areaMax / buildArea / landArea / projectCompany / plotRatio / greenRate / buildingTotal / houseTotal / deliveryDate / propertyCompany / decorateType / houseType / salesAddress / projectAddress 及各配套字段
4. `LoupanController.java` 新增接口：
   ```
   POST /api/admin/loupans/ai-parse
   Content-Type: multipart/form-data
   参数: files (多文件)
   返回: { fields: {...}, rawText: "完整识别文本" }
   ```

### 前端实现

1. "新建楼盘"按钮右侧添加"AI新增楼盘"按钮（theme="warning" outline + Sparkles 图标）
2. 新建 `<t-dialog>` 弹窗：
   - 上传区域：`<t-upload>` 支持多图（accept="image/*"），最多 5 张
   - 图片预览：缩略图列表
   - "开始识别"按钮：至少上传 1 张才可点击
   - 识别状态：Loading + "正在识别中，请稍候..."
   - 结果预览：`<t-table>` 展示识别字段（字段名 | 识别值 | 可信度标签）
   - "修改后确认填入"和"放弃"按钮
3. 确认后调用 `openCreate()` 打开 form drawer，用识别结果填充 form 各字段
