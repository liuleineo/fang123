# 2026-10-19 客户信息流：点击头像修改客户资料

## 需求

客户信息流（`/customer-feed`）中点击客户头像，可以修改该客户的资料。

## 实现（前端 `web/src/views/CustomerFeed.vue`）

**入口**：头像改为可点击，并在右下角加一个小铅笔角标，避免用户不知道这里能点（`title="点击修改客户资料"`，`@click.stop` 不影响上下滑动切换）。

**编辑弹窗**（深色，复用 `.feed-dark-dialog` 样式）：姓名、手机号、意向（高/中/低，再点取消）、需求备注，底部保存。

**保存**：`PUT /user/customers/{id}`，body 只带 `name/phone/intention/remark`。
后端这个接口内部是 `updateById`，MyBatis-Plus 默认忽略 null 字段，所以只改这四个字段不会影响其它字段。
被共享的客户只有归属人能改，接口会返回"客户不存在"，前端据此提示
「仅客户归属人可以修改资料」。

## 踩到的坑

第一版保存成功后用接口返回的客户对象整体 `Object.assign(c, updated)` 回填，
结果卡片上的「已 49 天未跟进」变成了「还没有跟进过」——
因为 `update` 返回的是裸客户记录，没有 `lastFollowUpTime` 这类列表接口额外补充的字段，整体覆盖把它们抹成 null。

改为**只回填本次编辑的四个字段**：`Object.assign(c, payload)`。

## 验证（playwright + 实库）

```
点击头像 → 弹窗打开，带出 姓名/手机号/意向(高,红色选中)/备注(学区房需求)
备注改为 "e2e-备注2" → 保存
  DB: customers.id=1 remark → e2e-备注2   ✓
  卡片: "王女士 高意向 12366668888 已 49 天未跟进 e2e-备注2"（未跟进天数保留）✓
  弹窗已关闭（offsetParent === null）✓
  name / phone / intention 未被误改 ✓

验证后已恢复备注为「学区房需求」
```
