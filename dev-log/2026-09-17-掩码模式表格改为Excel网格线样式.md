# 掩码成交价模式下：真实成交表格切换为 Excel 网格线样式

日期：2026-09-17
页面：`/loupan/:id/real-deal`（同板块真实成交）
文件：`web/src/views/LoupanSubPage.vue`（仅前端，纯样式）

## 需求

点击「掩码成交价」后，真实成交数据以**带网格线的表格**呈现（类似 Excel 单元格边框）；未掩码时保持原有清爽样式。

## 改动

1. 表格容器：掩码时外框由 `border-gray-100` 加深为 `border-gray-300`
   ```html
   <div v-else-if="plateDeals.length" class="overflow-x-auto bg-white rounded-xl border"
        :class="maskDealPrice ? 'border-gray-300' : 'border-gray-100'">
   ```
2. 表格内部网格线：掩码时通过 Tailwind 任意变体为所有 `th`/`td` 加 1px 边框，表头底色加深
   ```html
   <table class="w-full text-sm border-collapse"
          :class="maskDealPrice ? '[&_th]:border [&_th]:border-gray-300 [&_th]:bg-gray-100 [&_td]:border [&_td]:border-gray-200' : ''">
   ```

说明：表格本身为 `border-collapse`，相邻边框自动合并，不会出现 2px 双线，视觉与 Excel 一致。

## 效果

- 掩码开启：成交单价列隐藏 + 全表格显示灰网格线（Excel 风格）
- 掩码关闭：恢复无竖线的轻量列表样式，成交单价列恢复
