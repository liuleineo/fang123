# 2026-09-12 一房一价管理：新增"批量设置单元""批量设置状态"

## 需求

管理端一房一价页（`/admin/yfyj`）在"批量设预售证号"之后，新增"批量设置单元"与"批量设置状态"两个批量操作，交互复用现有批量设置弹窗模式。

## 改动

### 前端 `admin/src/views/LoupanYfyjManage.vue`

- 筛选栏新增两个按钮（`Tag` 图标，位于"批量设预售证号"右侧）：
  - `批量设置单元` → `openBatch('unitNo')`
  - `批量设置状态` → `openBatch('houseStatus')`
- `batchMeta` 扩展 `unitNo`（单元号 / 批量设置单元）、`houseStatus`（房源状态 / 批量设置状态）
- 新增 `houseStatusOptions`（未售0 / 认购1 / 已售2 / 抵押3 / 保留4），与新建/编辑表单下拉保持一致
- 批量弹窗输入控件按类型分支：
  - `houseStatus` → `t-select` 下拉选择
  - `permitNo` / `unitNo` → `t-input` 文本输入（单元号提示"输入单元号，如 1"）
  - 其余 → `t-input-number`
- `doBatchUpdate` 的 `keyMap` 扩展 `unitNo → setUnitNo`、`houseStatus → setHouseStatus`；文本类字段（`permitNo` / `unitNo`）统一 `String().trim()`，状态以数字提交

### 后端 `backend/src/main/java/com/fang123/controller/LoupanYfyjController.java`

- `POST /api/admin/yfyj/batch-update` 的 set 分支新增：
  - `setUnitNo` → `LambdaUpdateWrapper.set(LoupanYfyj::getUnitNo, ...)`（字符串）
  - `setHouseStatus` → `LambdaUpdateWrapper.set(LoupanYfyj::getHouseStatus, ...)`（整数）
- 空值保护：新增 `toIntOrNull` 辅助方法（与 `toLongOrNull` 同风格）
- 未指定任何 set 字段时的错误提示补充为 `setLoupanId / setHuxingId / setPermitNo / setUnitNo / setHouseStatus`

## 备注

- where 筛选条件（楼盘ID / 楼栋 / 单元 / 房号 / 预售证号）复用原有逻辑，未改动
- 状态值 0（未售）在前端校验中通过 `String(0)` 判定，不会被误判为空
