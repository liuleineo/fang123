# 2026-11-07 楼盘表增加「优点 / 缺点」字段

## 需求

`loupan` 表增加优点、缺点两个字段，管理端可录入。

## 改动

### 1. 建表语句（`backend/src/main/resources/db/schema.sql`）

`loupan` 表在 `view_support` 之后新增：

```sql
`advantage` text COMMENT '楼盘优点',
`disadvantage` text COMMENT '楼盘缺点',
```

### 2. 实体（`backend/src/main/java/com/fang123/entity/Loupan.java`）

```java
/** 楼盘优点 */
private String advantage;
/** 楼盘缺点 */
private String disadvantage;
```

MyBatis-Plus 默认驼峰映射，对应列 `advantage` / `disadvantage`；
新增/编辑接口是 `@RequestBody Loupan entity` + `save/updateById`，不需要改 Controller/Service。

### 3. 管理端表单（`admin/src/views/LoupanManage.vue`）

- 「基本信息」tab 的样板房说明下方，并排两个多行文本域：**楼盘优点** / **楼盘缺点**
  （`t-textarea`，自动 3~8 行，带填写示例 placeholder）
- `initForm()` 补上 `advantage:''`、`disadvantage:''`，新建时清空、编辑时由 `Object.assign(form, row)` 自动回填

### 4. 数据库变更（需在库上执行）

本地 3306 的 MySQL 当前不可连接，未能直接执行，部署时请执行：

```sql
ALTER TABLE `loupan`
  ADD COLUMN `advantage` text COMMENT '楼盘优点' AFTER `view_support`,
  ADD COLUMN `disadvantage` text COMMENT '楼盘缺点' AFTER `advantage`;
```

## 验证

- `mvn -DskipTests compile` 通过
- `cd admin && npm run build` 通过，`admin/dist` 已更新
