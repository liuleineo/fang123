# 2026-08-20 土拍地图（tupai-map）增加卫星地图切换按钮

## 改动内容

`web/src/views/TupaiMap.vue`（/tupai-map 土拍地图页面）：

1. 地图容器右下角新增"卫星/地图"切换按钮（白底 + Map/Satellite 图标）
2. 地图初始化时创建卫星图层 `AMap.TileLayer.Satellite` 和道路标注 `AMap.TileLayer.RoadNet`（默认不显示）
3. 新增 `showSatellite` ref 和 `toggleSatellite()` 函数：`map.add/remove` 切换卫星图
4. 图标导入：`Map` 重命名为 `MapIcon`，新增 `Satellite as SatelliteIcon`

## 修复

- 首次编译报语法错误（toggleSatellite 函数后多一个闭合大括号），已删除多余 `}`，编译通过

## 交互效果

土拍地图右下角点击"卫星"切换卫星影像（叠加道路标注），再点切回标准地图。与 school-map / map 页面一致。
