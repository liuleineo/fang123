# 2026-10-04 地图找房（/map）缩放级别 > 14 时，楼盘标记下方显示户型面积范围与总价范围

## 需求

`https://hangfang123.com/map` 地图找房页面，当地图缩放级别大于 14 时，在楼盘标记的名称下方增加显示：

- 户型面积范围（最低面积-最高面积）
- 总价范围：最低总价-最高总价

缩放级别回到 14 及以下时不显示这两行，保持原有单行标签。

## 改动（`web/src/views/MapSearch.vue`）

### 1. 新增阈值开关与格式化方法

```js
// 缩放级别大于该值时，在楼盘名称下方显示户型面积、总价范围
const ZOOM_DETAIL_LEVEL = 14
const showMarkerDetail = ref(false)
// marker 与楼盘数据的对应关系：缩放跨过阈值时只刷新标签，不重建标记（避免触发重新定位）
let markerItems = []

/** 户型面积范围：90-140㎡（只有一个值时降级为 90㎡） */
function formatAreaRange(lp) { ... }

/** 总价范围：180-260万（数据库单位为万元） */
function formatTotalPriceRange(lp) { ... }
```

- 面积用 `areaMin/areaMax`（㎡），总价用 `minTotalPrice/maxTotalPrice`（万元，与后台字段单位一致）；
- 两个值都存在且不同时输出区间；数值缺失时取另一侧单值输出（如 `105㎡`）；两侧都为空则不输出该行，标签不出现空行；
- 这两个字段在 `/api/public/loupans?light=true` 精简查询中已返回（`LoupanPublicController` 第 60-66 行 `select` 已包含 `areaMin/areaMax/minTotalPrice/maxTotalPrice`），**无需改动后端**。

### 2. 缩放跨过阈值时刷新标签（不重建标记）

```js
function syncZoom() {
  if (!mapInstance) return
  const z = Number(mapInstance.getZoom())
  zoomLevel.value = Number.isFinite(z) ? Math.round(z * 10) / 10 : ''
  const next = Number.isFinite(z) && z > ZOOM_DETAIL_LEVEL
  if (next !== showMarkerDetail.value) {
    showMarkerDetail.value = next
    updateMarkerLabels()
  }
}

/** 缩放跨过阈值时按当前级别刷新所有标记标签（不重建标记，避免视野被重置） */
function updateMarkerLabels() {
  markerItems.forEach(({ marker, lp }) => {
    marker.setLabel({ content: buildLabelContent(lp), direction: 'top' })
  })
}
```

- 关键点：只调用 `marker.setLabel()` 刷新内容，**不重新执行 `addMarkers()`**，因为 `addMarkers()` 末尾会 `setFitView()`，重建标记会导致视野/缩放被重置，形成缩放抖动；
- 仅在阈值真正跨越时（`next !== showMarkerDetail.value`）才刷新标签，缩放过程中的连续 `zoomchange` 不会反复重排 DOM。

### 3. 标签 HTML 拆为 `buildLabelContent(lp)`

- 第一行保持原样：楼盘名称 + 均价（万/㎡，高层为空时回退洋房/叠墅/排屋）；
- `showMarkerDetail` 为真时，容器改为纵向排列，追加：
  - `户型面积：100-166㎡`（浅蓝 `#BAE0FF`，11px）
  - `总价范围：280-460万`（浅黄 `#FFE58F`，11px，与均价强调色一致）

## 验证（本地 `http://localhost:4000/map` + 本地 MySQL）

| 场景 | 结果 |
|---|---|
| 页面加载（fitView 后缩放 17 > 14） | 标签为「楼盘名 \| 2.8万/㎡ \| 户型面积：100-166㎡」✅ |
| 缩放级别 16 | 显示户型面积行 ✅ |
| 缩放级别 13 | 只显示「楼盘名 \| 2.8万/㎡」，无明细行 ✅ |
| 缩放级别 14（边界，不大于 14） | 不显示明细行 ✅ |
| 总价有数据时（临时将某楼盘总价置为 280-460 万后重载） | 显示「总价范围：280-460万」✅ |
| 总价无数据（线上当前两个楼盘 min/max 总价均为空） | 不显示总价行，不出现空行 ✅ |
| 数据还原 | 临时测试数据已改回原值（`min_total_price/max_total_price = NULL`，`area_max = 330`）✅ |

说明：滚轮/双击的合成事件不被高德内部手势逻辑接受，故缩放测试通过容器上的高德实例 `document.getElementById('amap-container').amap.setZoom(n)` 触发，链路与真实缩放一致（同样走 `zoomchange/zoomend`）。
