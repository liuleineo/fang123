# 2026-08-15 修复真实成交页空白 bug

## 问题

`http://localhost:3000/admin/real-deals` 页面显示空白。

## 原因

在 `admin/src/views/RealDealManage.vue` 中，`watch(() => form.communityName, ...)` 被定义在 `const form = reactive(initForm())` **之前**。

Vue 3 的 `watch` 即使未设置 `immediate`，在 `doWatch` 初始化时也会先执行一次 getter 获取初始值（用于后续对比）。此时 `form` 仍处于 `const` 的暂时性死区（TDZ），导致 `ReferenceError: Cannot access 'form' before initialization`，整个组件 `<script setup>` 抛出异常，页面渲染中断显示空白。

## 修复

将 `watch(() => form.communityName, ...)` 移到 `const form = reactive(initForm())` 定义之后。

## 说明

- admin dev 服务器热更新后页面恢复
- 功能不变：小区名称变化时按小区名搜索加载楼盘下拉选项
