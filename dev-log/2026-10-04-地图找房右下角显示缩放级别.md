# 2026-10-04 地图找房（/map）右下角显示缩放级别

## 需求

`https://hangfang123.com/map`（地图找房）页面，在地图右下角显示当前地图缩放级别。

## 改动（`web/src/views/MapSearch.vue`）

### 1. 右下角新增缩放级别展示

原有的右下角容器（`absolute bottom-6 right-4`，里面是「卫星/地图」图层切换按钮）改为横向排列：**缩放级别徽标在左、图层切换按钮在右**，保持原有 `bottom-6 / right-4` 定位，视觉风格与图层按钮统一（白底、圆角、阴影、灰边框）：

```html
<div class="absolute bottom-6 right-4 z-20 flex items-center gap-2">
  <!-- 缩放级别（随地图缩放实时更新） -->
  <div
    v-if="mapReady"
    class="flex items-center gap-1 px-2.5 py-1.5 rounded-lg bg-white/95 backdrop-blur-sm text-xs font-medium text-gray-700 shadow-md border border-gray-200 select-none tabular-nums"
    :title="`当前地图缩放级别：${zoomLevel} 级（3~20 级，数字越大越详细）`"
  >
    <span class="text-[var(--color-text-tertiary)]">缩放级别</span>
    <span class="font-bold text-[var(--color-primary)]">{{ zoomLevel }}</span>
  </div>
  <button ...图层切换按钮（不变）... />
</div>
```

细节：

- `v-if="mapReady"`：地图加载完成前不显示，避免加载遮罩层上出现无意义数字；
- `tabular-nums`：数字等宽，缩放时宽度不跳动；
- `title` 悬浮提示解释级别含义，避免「16」这种数字看不懂。

### 2. 缩放级别实时同步

```js
const zoomLevel = ref(12)

/** 同步右下角显示的缩放级别：高德 2.0 为 3~20 级，缩放动画过程中可能带小数 */
function syncZoom() {
  if (!mapInstance) return
  const z = Number(mapInstance.getZoom())
  zoomLevel.value = Number.isFinite(z) ? Math.round(z * 10) / 10 : ''
}
```

地图创建后立即同步一次并监听缩放事件：

```js
  syncZoom()
  mapInstance.on('zoomend', syncZoom)
  mapInstance.on('zoomchange', syncZoom)
```

- 同时监听 `zoomchange`（缩放过程中）与 `zoomend`（缩放结束），滚轮/双击/双指/程序化缩放都会触发，覆盖 `focusLoupan()` 里 `setZoomAndCenter(16, ...)` 与 `addMarkers()` 里 `setFitView(markers)` 引起的缩放；
- 数值保留 1 位小数（连续缩放时可能出现小数级别）；
- 初值设为页面默认 `zoom: 12`，避免地图就绪瞬间显示空值。
