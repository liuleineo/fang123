# 2026-09-27 客户列表：双击卡片复制手机号

## 需求

`/customers` 页面双击客户卡片，自动将该客户手机号复制到剪贴板，并给出提示。

## 改动（`web/src/views/Customers.vue`）

1. 卡片容器绑定双击事件与提示文案：

```html
<div v-for="c in list" :key="c.id" class="bg-white rounded-[4px] ..."
     title="双击复制手机号" @dblclick="onCustomerDblClick($event, c)">
```

2. 新增双击处理与复制方法（位于 `syncListLastFollowUp` 之后）：

```js
/** 双击客户卡片：复制该客户手机号到剪贴板（点操作按钮时不触发） */
function onCustomerDblClick(e, c) {
  if (e.target.closest('button, a, input, [data-no-dbl-copy]')) return
  copyCustomerPhone(c)
}
async function copyCustomerPhone(c) {
  if (!c?.phone) { MessagePlugin.warning('该客户没有手机号'); return }
  try {
    await copyText(c.phone)
    MessagePlugin.success(`已复制手机号 ${c.phone}`)
  } catch (err) { MessagePlugin.error(err?.message || '复制失败，请手动复制') }
}
```

3. 头像（点击进入编辑）区域加 `data-no-dbl-copy`，避免「双击头像打开编辑」时同时触发复制：

```html
<div class="w-10 h-10 ... cursor-pointer overflow-hidden" data-no-dbl-copy @click="openEdit(c)" title="点击编辑客户">
```

复制能力复用 `web/src/utils/clipboard.js` 的 `copyText`（Clipboard API + execCommand 降级），兼容 HTTPS/WebView 环境。无手机号的客户双击时提示「该客户没有手机号」。

## 验证（本地实测）

临时注册测试用户（13900005680）并创建 1 条客户（双击验证客户C / 13800138002），浏览器（agent-browser）注入登录态实测，并临时挂钩 `navigator.clipboard.writeText` 捕获真实写入内容：

| 场景 | 结果 |
|---|---|
| 双击卡片信息区 | 提示「已复制手机号 13800138002」，捕获到写入剪贴板的文本 = `13800138002` ✅ |
| 双击「跟进记录」等操作按钮 | 不触发复制（无提示、无写入），按钮原功能正常 ✅ |
| 双击头像（编辑区） | 打开编辑抽屉，未触发复制 ✅ |

说明：headless 浏览器读取剪贴板需授权（`readText` 被拒），故采用「提示仅在 `copyText` 成功 resolve 后出现 + 挂钩 writeText 捕获入参」双重确认。
