# 2026-11-13 新盘信息列表：每页可选 200 条 + 生成海报

## 需求

1. `/xinpanlist` 分页每页条数增加 200 选项
2. 参照 `/loupan/:id/yfyj`（一房一价）的海报能力，新盘信息列表也能生成海报图片

## 实现（仅前端 `web/src/views/XinpanList.vue`）

### 1. 分页每页 200 条

```html
:page-size-options="[20, 50, 100, 200]"
```

选中后请求参数为 `size=200`，后端无需改动。

### 2. 生成海报

沿用一房一价的实现思路：**Canvas 手绘，不引入截图库**（文字更清晰、无跨域图片问题）。

- 入口：右下角悬浮按钮 `.poster-fab`（`position: fixed`，避开 iPhone 安全区，仅在有数据且非加载中时渲染），点击 `openPoster()`
- 弹窗：loading → `poster-preview` 等比预览（`max-height: 60vh`）→「关闭 / 保存图片」
- 保存：`<a download>`，文件名 `杭州新盘信息-YYYY-MM-DD.png`
- 关闭弹窗 300ms 后清空 `posterUrl`，释放几 MB 的 dataURL

海报内容（画布宽 1800，10 列合计 1736）：

| 区块 | 内容 |
| --- | --- |
| 标题区（蓝渐变 148px） | 主标题「杭州新盘信息」；副标题 = 销售状态 · 区域 · 关键词；右上角日期、站点、`共 N 个楼盘`（超过 30 条时标注「海报展示前 30 个」） |
| 表头 | 区域 / 楼盘名称 / 板块 / 开发商品牌 / 面积段 / 单价 / 总价范围 / 物业费 / 优点 / 缺点 |
| 数据行 | 行高按内容动态计算（56px 起），名称蓝色加粗、价格红色右对齐、品牌最多 2 行、优点/缺点最多 3 行超出加「…」，奇偶行浅灰底 |
| 页脚 | 数据来源、免责声明、生成时间 |

关键细节：

- **`POSTER_MAX_ROWS = 30`**：海报最多画 30 条，避免 200 条/页时画布过大（iOS Safari 单画布面积上限约 1670 万像素，超了会得到空白图）
- **倍率自适应**：默认 2 倍，按 `W*H*scale² ≤ 1200 万像素` 逐级降到 1.75/1.5…，实测 30 行时为 1.5 倍（2700×3807）
- 文本工具：`posterEllipsis()` 单行截断、`posterWrapAll()` 逐字换行、`posterFont()` 统一字体栈
- 排版：先用离屏 canvas `measureText` 预计算每行单元格文本与行高，再建正式画布绘制，避免二次测量
- 取数与页面一致：复用 `areaText / unitPriceText / totalPriceText / feeText`，口径与表格完全统一
