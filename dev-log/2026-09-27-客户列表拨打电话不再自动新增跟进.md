# 2026-09-27 客户列表：拨打电话按钮不再自动新增跟进

## 需求

`/customers` 页面点击「拨打电话」按钮时，不再自动写入一条「拨打了客户电话」跟进记录，只保留拨号行为。

## 改动（`web/src/views/Customers.vue`）

1. 模板：移除拨号链接上的自动跟进事件，`href` 拨号行为保留：

```html
<!-- 之前 -->
<a v-if="c.phone" :href="`tel:${c.phone}`" title="拨打电话" @click="recordPhoneCall(c)" ...>
<!-- 现在 -->
<a v-if="c.phone" :href="`tel:${c.phone}`" title="拨打电话" ...>
```

2. 脚本：删除 `recordPhoneCall()` 函数（原先静默 `POST /user/customers/{id}/follow-ups`，content=「拨打了客户电话」，method=「电话」），全站已无该函数引用。

保留不变：`addFollowUp()` 手动添加跟进及其 `syncListLastFollowUp()` 列表即时更新逻辑照常生效。
