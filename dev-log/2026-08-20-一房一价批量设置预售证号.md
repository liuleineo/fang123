# 2026-08-20 一房一价支持批量设置预售证号

## 改动内容

在既有批量设置功能基础上扩展支持批量设置**预售证号（permit_no）**。

### 后端 LoupanYfyjController.java
`/api/admin/yfyj/batch-update` 接口新增 `setPermitNo` 字段支持：
- 接收 `setPermitNo`（字符串），`uw.set(LoupanYfyj::getPermitNo, value)`
- 校验逻辑更新：setLoupanId / setHuxingId / setPermitNo 三选一

### 前端 LoupanYfyjManage.vue
1. 搜索区新增"批量设预售证号"按钮
2. 批量设置对话框支持文本输入（预售证号为字符串，用 t-input；楼盘ID/户型ID 仍用 t-input-number）
3. 新增 `batchMeta` 映射（label/title），对话框标题和标签随类型变化
4. `doBatchUpdate` 根据类型选择 set 字段：`setLoupanId` / `setHuxingId` / `setPermitNo`；预售证号做 trim

## 交互效果

筛选房源后点击"批量设预售证号"，输入预售证号（如 杭房预许字（2026）第00001号），对筛选结果批量设置。
