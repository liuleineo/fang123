# 2026-11-07 Web 端新增「新盘信息」表格页面

## 需求

前台新增一个表格页面，集中展示新楼盘关键信息，字段：区域、楼盘名称、板块、开发商、面积段、单价、总价范围、物业费、优点、缺点。

## 实现

### 1. 路由与入口

- 新页面 `web/src/views/XinpanList.vue`，路由 `path: 'xinpan'`（name `XinpanList`，标题「新盘信息」）
- 顶部导航 `WebLayout.vue` 的 `navItems` 在「新盘」后新增 `{ label: '新盘信息', href: '/xinpan' }`

### 2. 数据

- 列表：`GET /api/public/loupans?page&size&keyword&district`（返回整条实体，已含新加的 `advantage` / `disadvantage`，记录带 `encodedId`）
- 筛选项：`GET /api/public/loupan-filters`（districts）

### 3. 字段展示口径

| 列 | 取值 |
| --- | --- |
| 区域 | `district` |
| 楼盘名称 | `projectName`，链到 `/loupan/{encodedId}` |
| 板块 | `plate` |
| 开发商 | `projectCompany` |
| 面积段 | `areaMin-areaMax ㎡`（相等或只有一个时显示单个） |
| 单价 | `avgUnitPrice`，为空回退洋房/叠墅/排屋均价，千分位 + 「元/㎡」 |
| 总价范围 | `minTotalPrice-maxTotalPrice 万` |
| 物业费 | `propertyFeeHigh` / `propertyFeeVilla`，两者不同显示区间，「元/㎡·月」 |
| 优点 / 缺点 | `advantage` / `disadvantage`，表格内两行截断（悬停看全文） |

### 4. 布局

- 桌面 / 平板：白卡片内表格，表头 sticky，横向滚动（10 列，`min-width: 1400px`），小于 `lg` 时显示「左右滑动」提示
- 手机（`< sm`）：切换为卡片列表，每条含楼盘名 + 区域·板块、开发商/面积段/单价/总价/物业费两列栅格，优点（绿）与缺点（红）整段展示
- 顶部筛选：区域下拉（clearable）+ 关键词搜索（支持回车/清空）+ 查询按钮；底部 `t-pagination`（20/50/100 条/页）
- 底部附数据来源与免责说明

## 前置条件

本页展示的「优点 / 缺点」依赖上一轮加的 `loupan.advantage` / `loupan.disadvantage` 列。
如果数据库还没执行，实体查询会因列不存在报错，请先执行：

```sql
ALTER TABLE `loupan`
  ADD COLUMN `advantage` text COMMENT '楼盘优点' AFTER `view_support`,
  ADD COLUMN `disadvantage` text COMMENT '楼盘缺点' AFTER `advantage`;
```
