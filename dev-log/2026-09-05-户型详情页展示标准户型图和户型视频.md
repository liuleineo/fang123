# 户型详情页(huxing子页)展示标准户型图和户型视频

日期：2026-09-05

## 需求

楼盘详情户型页（如 `/loupan/{id}/huxing`），户型卡片目前只展示「户型图」主图。考虑每个户型还可能存在：
- **标准户型图**：`loupan_huxing.standard_huxing_image` 字段
- **户型视频素材**：`loupan_media` 中 `huxing_id` 指向该户型、且 `media_type = 5` 的记录

希望在户型主图下方，以一行小缩略图展示以上补充素材（有则显示），缩略图体积不大，且支持点击放大/播放。

## 改动文件

`web/src/views/LoupanSubPage.vue`

### 1. huxing 子页加载时同步拉取媒体素材

原逻辑仅 `media` 子页才 `fetchMedias()`，现 `huxing` 子页也一并拉取，用于匹配各户型绑定的视频。

```js
if (subType.value === 'media' || subType.value === 'huxing') fetchMedias()
if (subType.value === 'huxing') fetchHuxings()
```

### 2. 新增户型补充素材汇总函数 `hxExtras(hx)`

返回该户型需展示的补充素材数组：

- `standardHuxingImage` 存在 → 追加 `{ kind: 'image', label: '标准户型图' }`
- 素材库中 `huxingId === hx.id && mediaType === 5` 的记录 → 追加 `{ kind: 'video', label: '户型视频' }`

### 3. 户型卡片主图下方新增缩略图行

- 图片用 `<img>`，视频用 `<video muted playsinline preload="metadata">`，外框 `w-20 h-20` 圆角小图，视频带播放图标遮罩，图下方有文字标签。
- 点击图片 → 复用全屏 `t-image-viewer` 放大
- 点击视频 → 打开 `t-dialog` 弹窗内 `<video controls autoplay>` 播放

```js
function previewHuxingExtra(hx, ex) {
  if (ex.kind === 'video') {
    huxingVideoUrl.value = ex.url
    huxingVideoVisible.value = true
  } else {
    viewerImages.value = [ex.url]
    viewerIndex.value = 0
    viewerVisible.value = true
  }
}
```

### 4. 新增户型视频播放弹窗

`t-dialog` header「户型视频」，宽度 720px，无 footer，内容为 `<video controls autoplay playsinline>`，最大高度 70vh。

## 效果

- 户型有标准户型图时，主图下方出现「标准户型图」小图，点击可全屏查看。
- 户型有绑定短视频素材时，主图下方出现带播放图标的「户型视频」小图，点击弹窗播放。
- 两者皆无时不占空间。
