# 2026-09-07 素材上传进度条一直 0% 后直接完成 修复

## 问题现象

admin `/medias`（素材管理）"新建视频素材/新建素材"上传文件时，TDesign `t-upload` 的进度条始终停在 0%，直到上传完成后瞬间跳到完成。

## 根因

- `t-upload` 使用自定义 `request-method`（`uploadRequest` 内部走 axios）时，TDesign 组件**不会自动推进 `file.percent`**：源码中自定义上传分支只会在 Promise resolve 时把文件置为 success/100%。
- 进度条展示读取的是 `file.percent`，而此前 axios 上传中途从未更新它 → 一直 0%，完成后被置 100%。

## 改动

`admin/src/views/LoupanMediaManage.vue`：

1. 给上传控件加 `ref="uploadRef"`
2. 新增 `updateUploadPercent(f, pct)`：直接更新 `file.percent`，并优先调用组件实例方法 `uploadFilePercent({ file, percent })` 保证响应式刷新
3. `uploadRequest()` 的 axios 请求增加 `onUploadProgress`：实时计算百分比（封顶 99%，避免与组件成功置 100% 冲突）同步到 t-upload
