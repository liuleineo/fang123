# 2026-09-02 web 客户列表增加搜索筛选功能

## 需求

`https://hangfang123.com/customers` 客户列表，在"批量添加"按钮上方增加"搜索"按钮，点击弹出筛选面板：
1. 支持按购房意向（高/中/低）筛选
2. 支持按最后跟进时间排序 / 正倒序切换

## 改动

### 后端（UserCustomerController.java）

- 列表接口 `GET /api/user/customers` 新增参数：
  - `intention`：意向筛选（eq 客户意向）
  - `sortField=lastFollowUpTime` + `sortOrder=asc/desc`：按最后跟进时间排序
- 排序实现：子查询 `(SELECT MAX(follow_up_time) FROM follow_ups fu WHERE fu.customer_id = customers.id)`，先按"是否为空"排序（**无跟进记录的排最后**），再按时间正/倒序

### 前端（web/src/views/Customers.vue）

1. **搜索按钮**：右下角操作按钮组最上方新增（Search 图标，绿色），移动端只显示图标
2. **筛选弹窗**：意向下拉（全部/高/中/低）+ 排序方式下拉（默认最新添加 / 最后跟进新→旧 / 旧→新）+ 重置/确定按钮
3. `fetchData` 携带筛选参数；应用/重置后回到第 1 页刷新

## 验证

- 后端编译重启成功，接口实测：
  - `intention=高` → 仅返回意向高的客户
  - 按最后跟进时间倒序 → 有跟进的客户在前、无跟进的排后
- web 编译通过，测试数据已清理
