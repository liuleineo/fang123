# 2026-09-27 同板块成交表格与真实成交表格样式统一

## 需求

用户要求「统一」——将 real-deal 页面「同板块真实成交」表格的样式与「真实成交」主表对齐：同样的 Excel 风格网格边框 + 同样紧凑的内边距。

## 改动文件

`web/src/views/LoupanSubPage.vue`（同板块真实成交表格，约 263 行起）

### 1. 网格线改为常驻

```html
<!-- 改动前：仅掩码状态显示网格 -->
<table class="w-full text-sm border-collapse" :class="{ 'plate-grid': maskDealPrice }">
<!-- 改动后：常驻，与主表 deal-grid 一致 -->
<table class="w-full text-[13px] border-collapse plate-grid">
```

掩码成交价按钮的职责回归为「隐藏成交单价列」，不再影响表格边框（`maskDealPrice` 仍用于单价列 `v-if` 与 `plateUnitPrice()`）。

### 2. 单元格紧凑化（与主表完全一致）

| 项 | 改动前 | 改动后 |
| --- | --- | --- |
| 内边距 | `p-3` | `px-2.5 py-1.5` |
| 字号 | `text-sm`（14px） | `text-[13px]` |
| 行分隔线 | 行 `border-t border-gray-100` | 移除，由网格线统一提供 |
| 数字列 | 部分 `tabular-nums` | 成交时间/面积/一手买入价补上 `tabular-nums` |

### 3. CSS 注释同步

`<style scoped>` 中说明改为「Excel 风格网格线（两张成交表样式统一，常驻显示）」，`#dcdcdc` 框线 + `#f5f5f5` 表头底色不变。
