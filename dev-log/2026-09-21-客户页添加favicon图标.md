# 2026-09-21 /customers 页面添加自定义 icon

## 需求

为 http://localhost:4000/customers 页面添加浏览器标签图标，使用 `callicon.png`。

## 改动

### 1. 图标资源配置

- 源文件：`web/dist/assets/callicon.png`（用户提供，16.84 KB）
- 复制到：`web/public/assets/callicon.png`

> 放在 `public/` 是为了让 `vite build` 时自动拷贝到 `dist/assets/callicon.png`，避免 `dist` 被清空重建后图标丢失。

### 2. `web/src/views/Customers.vue`

在 `<script setup>` 末尾新增页面级 favicon 逻辑：

- `setCustomerFavicon()`：记录当前 `<link rel="icon">` 的 `href/type` 快照，预加载 `/assets/callicon.png`，加载成功后切换为客服图标（`image/png`）；加载失败仅告警，不改动原图标。
- `restoreFavicon()`：还原快照（默认 `/favicon.svg` + `image/svg+xml`）。
- 在已有的 `onMounted` 中调用 `setCustomerFavicon()`，`onUnmounted` 中调用 `restoreFavicon()`；原有 `fetchData()`、`resize` 监听逻辑不变。

## 验证

| 项 | 结果 |
| --- | --- |
| lint | 无错误 |
| dev 访问图标 | `GET /assets/callicon.png` → 200，`image/png`，17247 bytes |
| 文件位置 | `web/public/assets/callicon.png`、`web/dist/assets/callicon.png` 均在位 |

## 备注

- 进入 `/customers` 标签页图标变为 callicon，离开该页面自动恢复站点默认图标。
- 站点默认 `/favicon.svg` 本身未在 `web` 目录中找到（构建产物 `dist` 根目录也没有），如需全局图标可后续补充。
- favicon 缓存较强，验证时建议硬刷新或关闭标签页重开。
