# 2026-08-13 楼盘详情页改为纵向展示 + 图库/户型/一房一价独立子页面

## 需求背景

为更好适配手机端，取消 `LoupanDetail.vue` 的 tab 方式展示，改为从上到下的纵向顺序展示；同时顶部预留"图库 / 户型 / 一房一价"三个入口按钮，点击后 SPA 内路由跳转到独立子页面查看详细信息。

## 改动内容

### 1. 路由新增（web/src/router/index.js）
新增三个独立子路由（复用 LoupanSubPage.vue，按路由 name 区分类型）：
- `loupan/:id/media` → 图库
- `loupan/:id/huxing` → 户型
- `loupan/:id/yfyj` → 一房一价

### 2. 新建 LoupanSubPage.vue
一个通用子页面组件，根据 `route.name` 判断 `subType`（media / huxing / yfyj），分别渲染：
- 图库：按媒体类型分组展示
- 户型：完整户型列表卡片
- 一房一价：楼栋切换 + 单元网格表格
- 数据获取逻辑（huxings/medias/yfyj）从原 LoupanDetail 中提取复用

### 3. 重构 LoupanDetail.vue
- 移除 `<t-tabs>` 结构，改为从上到下的纵向区块：
  1. 楼盘位置（地图 + 周边配套）
  2. 户型信息（横滑展示前 6 个，附"查看全部 ›"链接）
  3. 楼盘信息（基本信息 / 建筑指标 / 开发信息 / 车位 / 外立面 / 样板房 / 小区配套）
  4. 开盘信息（预售证表格）
- 头部信息区下方新增三个快捷入口按钮：图库 / 户型 / 一房一价（theme=primary outline），SPA 内跳转到对应子路由
- 移除原 tab 中的图库、一房一价 tab 内容及对应 medias/yfyj 逻辑（移至子页面）
- 地图初始化改为 onMounted 后直接调用（不再依赖 tab 切换）

## 交互效果

- 手机端进入楼盘详情页，从上到下顺序浏览：位置 → 户型概览 → 楼盘信息 → 开盘信息，无需切换 tab
- 顶部三个按钮可进入对应完整详情子页面，可返回

## 说明

- 已重新编译 web 端（`npm run build`）成功，新增 `LoupanSubPage-*.js` chunk
- 若需线上生效，需将 `web/dist` 部署到线上服务器
