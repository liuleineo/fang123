# 2026-09-08 管理后台移动端适配（侧边栏收起 + 全页面检查）

## 需求

管理后台（/admin/**，如 dashboard）适配手机端：左侧菜单在手机端收起为抽屉（汉堡唤出），并排查所有管理页面的窄屏显示问题。

## 改动

### 1. 布局 `admin/src/layouts/AdminLayout.vue`
- **修复移动端侧边栏未真正收起的问题**：此前 `isMobile` 时 aside 虽 `fixed` 但始终平铺在屏幕左侧遮挡内容。现按 `sidebarOpen` 切换 `-translate-x-full` / `translate-x-0`（抽屉式滑出/收起），打开时加阴影
- 内容区 `p-6` → `p-3 md:p-6`（手机端留白减小）

### 2. 全局样式 `admin/src/styles/global.css`（<768px 媒体查询新增）
- 抽屉 `.t-drawer` 占满屏宽（100vw），避免 450/560px 宽度内容被截断
- 弹窗 `.t-dialog` 宽度自适应 `calc(100vw - 24px)`，内容左右留 16px
- 固定宽度筛选控件（w-[220px] 等）`max-width:100%`，窄屏自动收缩不撑破容器
- 日期区间控件不溢出

### 3. 各页面顶部操作区 + 筛选区支持换行（~15 个页面）
- 页面标题/按钮区 `flex` → `flex flex-wrap ... gap`（PresalePermit、LoupanHuxing、LoupanTupaiLand、School、Loupan、LoupanMedia、Customer、Task、RealDeal、LoupanYfyj、LoupanDynamic、Member 等）
- 卡片内筛选行补 `flex-wrap`（同上各页 + MemberUsers、Invite）
- 表单密集网格手机端降列：`grid-cols-3/4/6` → 手机 1~2 列（≥640px 保持原列数）

## 验证建议
- 用浏览器设备模拟（<768px）逐页检查：菜单抽屉开合、各列表筛选/按钮换行、抽屉与弹窗不截断、表格可左右滚动
