# 2026-08-30 web 端客户列表显示分享关系

## 需求

`http://localhost:4000/customers` 客户列表，在客户电话后面显示"分享给了谁"或"被谁分享"。

## 改动

### 后端

1. **`Customer.java`**：新增非表字段 `shareDesc`（分享关系描述文本）

2. **`UserCustomerController.java`**：列表接口新增 `fillShareDesc` 方法
   - 查询当前用户作为原拥有人（owner）的分享记录 → 拼"分享给了 张三、李四"
   - 查询当前用户作为被分享人（shared）的分享记录 → 拼"王五 分享给我"
   - 两种关系同时存在时用" · "拼接

### 前端（web/src/views/Customers.vue）

- 客户卡片电话后新增紫色小字展示 `shareDesc`（带 Share2 图标），无分享关系不显示

## 验证

- 后端编译重启成功，双用户实测：A 分享客户给 B（小王），A 列表该客户正确显示"分享给了 小王"，测试数据已清理
