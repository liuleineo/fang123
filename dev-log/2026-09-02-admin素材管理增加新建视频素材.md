# 2026-09-02 admin 素材管理增加"新建视频素材"按钮

## 需求

`https://hangfang123.com/admin/medias` 素材管理页，在"新建素材"按钮前增加"新建视频素材"按钮。

## 改动（admin/src/views/LoupanMediaManage.vue）

1. **按钮区**：在"新建素材"前新增"新建视频素材"按钮（Video 图标，outline 样式）
2. **`openVideoCreate`**：打开新建 drawer 并预置 `mediaType=5`（短视频，素材类型下拉禁用）
3. **drawer 标题**动态显示"新建视频素材"/"新建素材"
4. **上传 accept**：视频创建时限定 `video/*`，普通素材保持 `image/*,video/*`；视频不走前端图片压缩逻辑

后端无需改动（`loupan_media` 已支持 mediaType=5 短视频，上传接口已接受视频）。
