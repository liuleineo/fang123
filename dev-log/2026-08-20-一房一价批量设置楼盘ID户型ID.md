# 2026-08-20 一房一价支持批量设置楼盘ID/户型ID

## 需求

admin `/admin/yfyj` 一房一价页面，搜索筛选后支持批量设置 `loupan_id` 和 `huxing_id`。

## 改动内容

### 后端 LoupanYfyjController.java
新增接口：
```
POST /api/admin/yfyj/batch-update
Body: { loupanId?, buildingNo?, unitNo?, roomNo?, permitNo?, setLoupanId?/setHuxingId? }
```
- 筛选条件（loupanId/buildingNo/unitNo/roomNo/permitNo）作为 where
- `setLoupanId` / `setHuxingId` 指定要批量设置的字段
- 使用 `LambdaUpdateWrapper` 的 `set` + where 条件，`getBaseMapper().update(null, uw)` 返回受影响行数
- 新增辅助方法 `asStr`、`toLongOrNull`

### 前端 LoupanYfyjManage.vue
1. 搜索区新增"批量设楼盘ID"、"批量设户型ID"按钮（Tag 图标）
2. 新增批量设置对话框（t-dialog）：
   - 显示当前筛选条件描述（filterDesc）
   - 输入目标 ID
   - 确认后 POST `/admin/yfyj/batch-update`，带上当前筛选条件 + set 字段
   - 成功后提示更新条数并刷新列表

## 交互效果

- 筛选房源后点击"批量设楼盘ID"或"批量设户型ID"，弹出对话框
- 输入 ID 确认，对筛选结果所有房源批量设置对应字段
- 显示更新条数
