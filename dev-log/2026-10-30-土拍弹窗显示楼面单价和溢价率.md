# 2026-10-30 土拍地图弹窗：楼面单价 / 溢价率 真正有数据可用

## 背景

上一轮已在 `/tupai-map` 地块弹窗和 `/api/public/tupai-lands` VO 里加了 `floorUnitPrice` / `premiumRate`，
但线上看不到数字。排查后是两个原因叠加：

1. **数据本身是空的**：`loupan_tupai_land` 共 1103 条，只有 1 条有楼面价和溢价率。
   原因是 `TupaiResourceService.fetchOne()` 在导入时显式写了
   `setFloorUnitPrice(null)` / `setPremiumRate(null)`，`plotRatio`、`buildAreaLimit` 也一并置空。
2. 线上后端还没重新部署（接口返回里没有这两个字段）。

## 改动

### 1. 导入时自动计算（`backend/.../service/TupaiResourceService.java`）

平台详情接口只给「出让面积 + 容积率区间 + 起始价 + 成交价」，不直接给楼面价，改为自行折算：

```
容积率   = plotRatio.RJL_S（上限，缺失时回退 RJL_X）
计容建面 = assignmentArea × 容积率          → buildAreaLimit
楼面单价 = dealPrice(万元) × 10000 / 计容建面 → floorUnitPrice（取整）
溢价率   = (dealPrice - startPrice) / startPrice × 100 → premiumRate（两位小数）
```

- 容积率超过 `9.99`（`plot_ratio` 列是 `decimal(3,2)`）时不存该列，但不影响楼面价计算
- 起价/成交价缺失时对应字段留空，不写脏数据

### 2. 历史数据回填

用一次性脚本（`/tmp/backfill_tupai.py`，2 线程、每请求间隔 1s）遍历 `resource_id` 非空且价格为空的地块，
调平台 `queryResourceDetail` 取面积/容积率/价格，按上面公式算出后 `UPDATE` 两个空列
（`COALESCE` 写入，只填不覆盖）。共 1087 条待补。

抽查（resourceId `2070081528095965184`，未来科技城 YH090102-09）：
成交 132002 万、起始 114002 万、面积 29102㎡、容积率 2.2 →
楼面单价 **20617 元/㎡**、溢价率 **15.79%**，与手算一致。

### 3. 弹窗文案（`web/src/views/TupaiMap.vue`）

按需求口径把「楼面价」改为「**楼面单价**」，仍为千分位蓝色加粗；溢价率红色加粗；两个字段为空时整行不渲染。
