# 2026-08-22 土拍地图修复默认缩放未严格按13级

## 问题

`/tupai-map` 地图加载后默认缩放未严格为 13 级。

## 原因

`addMarkers()` 末尾的 `mapInstance.setFitView(markers)` 会根据地块标记分布**自适应调整缩放级别**，覆盖了初始化时的 `zoom: 13`。

## 修复

`web/src/views/TupaiMap.vue`：

1. 移除 `mapInstance.setFitView(markers)` 及其 `fitDone` 标志逻辑
2. 删除无用变量 `let fitDone = false`

## 效果

地图加载后严格保持初始化设置的缩放级别 13、中心 [120.21, 30.29]，不再被 setFitView 覆盖。

## 说明

- 已重新编译 web 端（`npm run build`）成功
- 若需线上生效，需将 `web/dist` 部署到线上服务器
