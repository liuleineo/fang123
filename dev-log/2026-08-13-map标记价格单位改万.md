# 2026-08-13 map 地图标记均价单位改为万/㎡

## 改动内容

`web/src/views/MapSearch.vue`（/map 地图找房页面）：

- 地图标记 label 的均价显示单位由"元/㎡"改为"万/㎡"：`avgUnitPrice / 10000`，保留最多 2 位小数（`Number(x.toFixed(2))`）
- 无均价仍显示"价格待定"

## 示例

- 30000元/㎡ → 3万/㎡
- 32500元/㎡ → 3.25万/㎡

## 说明

- 已重新编译 web 端（`npm run build`）成功
- 若需线上生效，需将 `web/dist` 部署到线上服务器
