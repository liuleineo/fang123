# 2026-09-27 客户列表：点击客户展开跟进记录（再次点击收起）

## 需求

`/customers` 客户列表中，点击某个客户后在其下方展开该客户的跟进记录；再次点击同一客户则收起。

## 改动（`web/src/views/Customers.vue`）

### 1. 模板

- 卡片容器增加选中态样式与点击交互提示，整行可点击：

```html
<div v-for="c in list" :key="c.id"
     :class="['bg-white rounded-[4px] border p-2.5 md:p-4 hover:shadow-md transition-all',
       expandedId === c.id ? 'border-blue-200 shadow-md' : 'border-gray-100']"
     title="点击展开跟进记录，双击复制手机号" @dblclick="onCustomerDblClick($event, c)">
  <div class="flex items-center gap-2.5 md:gap-3 cursor-pointer" @click="onCustomerClick($event, c)">
```

- 信息栏与操作按钮之间加展开箭头（桌面端显示，展开时旋转 180°）：`ChevronDown`。
- 卡片下方新增内联展开区（`v-if="expandedId === c.id"`）：标题「跟进记录 + 共 N 条」，加载中显示 loading，空态显示「暂无跟进记录」，有数据时按 `max-h-72` 可滚动列表展示 方式标签 / 操作人 / 时间 / 内容 / 图片缩略图（点击调用 `previewImages` 全屏预览）。

要点：

- **与双击复制手机号共存**：单击延迟 200ms 执行，`dblclick` 时清除该定时器，因此双击只复制手机号、不会「展开又收起」；`onCustomerDblClick` 增加清除逻辑。
- **不误触发**：点击操作按钮 / 电话链接 / 输入框 / 头像（`data-no-dbl-copy`）时直接返回，原有功能不受影响。
- **单开**：展开另一个客户时自动收起上一个。
- **数据同步**：抽屉内新增跟进后，若该客户正在展开状态，同步刷新内联跟进列表（`addFollowUp` 中追加 `if (expandedId.value === customerId) loadExpandedFollows(customerId)`）；随后端返回的最新数据。
- 抽屉（绿色「跟进记录」按钮）保留，用于新增跟进与图片上传等完整操作。
