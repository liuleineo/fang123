# 2026-11-18 首页楼盘按「预售公示 → 最新开盘 → 排序权重」顺序展示

## 需求

首页默认楼盘列表按三类依次展示：

1. **预售公示**中（公示期内）的楼盘
2. **最新开盘**（近 7 天取得预售证）的楼盘
3. **排序权重 > 0** 的楼盘，按 sort 从高到低

同一楼盘只出现一次，优先级取靠前的分组。

## 后端

### 1. `dto/LoupanSpotlightVO.java`

新增 `private String group;`（`presale` / `opening` / `sort`），类上已有 `@JsonInclude(NON_NULL)`，非分组场景不输出。

### 2. `controller/LoupanSpotlightController.java`

新增 `GET /api/public/loupan-home?page=1&size=12`：

- 复用已有 `presalePermits(today)` / `openingPermits(today)` 与 `matchedLoupans()`，保证口径与「预售公示 / 最新开盘」按钮完全一致
- 新增 `permitMap(permits)` 抽取「同一楼盘多张证只保留第一条」的逻辑（与原 list 接口一致）
- 依次拼装：
  1. 预售公示（公示日期倒序，与原板块一致）
  2. 最新开盘（核发日期倒序），`seen` 去重跳过已在前组的楼盘
  3. `sales_status = 1 AND sort > 0`，`ORDER BY sort DESC, create_time DESC`，再去重
- 返回 `{total, page, size, records}`，`records` 中每条 VO 带 `group`
- 分页在拼装后的完整列表上切片，因此「分组顺序」跨页保持

新增常量 `GROUP_PRESALE / GROUP_OPENING / GROUP_SORT`。

> 第三组限定「在售」，与首页原默认列表 `salesStatus=1` 的口径一致，避免售罄/待售楼盘挤进首页推荐位。

## 前端

### 1. `components/LoupanListSection.vue`

- 新增 prop `homeOrder: Boolean`（默认 false）
- 新增 `hasFilter` computed（关键词 / 行政区 / 板块 / 楼盘类型）
- `fetchData()`：
  - 首页模式且**无筛选** → `GET /public/loupan-home`
  - 有筛选条件 / 非首页（`/xinpan` 复用本组件）→ 仍走 `GET /public/loupans?salesStatus=1`
- 卡片底部新增分组标签，并沿用预售证日期展示：
  - `group=presale` → 「预售公示」+「公示 日期」「核发 日期」
  - `group=opening` → 「最新开盘」+「核发 日期」
  - `group=sort` → 「热门推荐」

### 2. `views/Home.vue`

```html
<LoupanListSection ref="listRef" v-model:spotlight="spotlightType" :show-keyword="true" :home-order="true" />
```

Hero 区「预售公示 / 最新开盘」切换按钮行为不变（仍按板块单独筛选）。
