# 2026-09-22 预售证管理：公示日期 / 核发日期支持粘贴输入

## 需求

`https://hangfang123.com/admin/presale-permits` 编辑（新建）预售证时，公示日期、核发日期除日历选择外，还要支持直接粘贴文本日期。

## 修改文件

`admin/src/views/PresalePermitManage.vue`

### 1. 模板：日期控件外层监听 paste

```html
<t-form-item label="公示日期">
  <div class="w-full" @paste="onDatePaste($event, 'publicityDate')">
    <t-date-picker v-model="form.publicityDate" class="w-full" clearable placeholder="选择或粘贴日期" />
  </div>
</t-form-item>
<t-form-item label="核发日期">
  <div class="w-full" @paste="onDatePaste($event, 'issueDate')">
    <t-date-picker v-model="form.issueDate" class="w-full" clearable placeholder="选择或粘贴日期" />
  </div>
</t-form-item>
```

说明：`paste` 事件从内部 `input` 冒泡到包裹 `div`，因此不依赖 TDesign DatePicker 是否透传原生事件，稳定可靠。

### 2. 脚本：日期文本解析 + 粘贴处理

```js
// 支持 2026-09-23 / 2026/9/23 / 2026.9.23 / 2026年9月23日 / 20260923 等格式
function parseDateText(raw) { ... }
function onDatePaste(e, field) { ... }
```

- 解析成功：`preventDefault()` 阻止组件自身插入原始文本，直接写入 `form[field]`（`YYYY-MM-DD`），并 `MessagePlugin.success` 提示
- 解析失败：不拦截，交回组件默认行为（不干扰正常使用）
- 校验：月份 1-12、日期 1-31，并用 `Date` 回验（拒绝 `2026-2-30`、`2026-13-01` 等非法日期）
