# 2026-08-16 楼盘增加洋房/叠墅/排屋均价字段

## 需求

`loupan` 表原有 `avg_unit_price`（默认高层均价），增加洋房、叠墅、排屋三个均价字段，方便分别录入不同物业类型均价。

## 改动内容

### 1. schema.sql
在 `loupan` 表 `avg_unit_price`（注释改为"高层楼盘均价 元/㎡"）之后新增三字段：
- `avg_unit_price_yangfang` int 洋房均价 元/㎡
- `avg_unit_price_dieshu` int 叠墅均价 元/㎡
- `avg_unit_price_paiwu` int 排屋均价 元/㎡

### 2. 实体 Loupan.java
新增字段 `avgUnitPriceYangfang` / `avgUnitPriceDieshu` / `avgUnitPricePaiwu`（MyBatis-Plus 自动驼峰转下划线映射）

### 3. admin LoupanManage.vue
- 表单："均价(元/㎡)"改为"高层均价(元/㎡)"，新增"洋房均价/叠墅均价/排屋均价"三个输入框
- `initForm()` 添加三字段初始值
- `fieldLabels` 添加三字段标签（AI 解析填入用）

### 4. 本机数据库
执行 ALTER TABLE 为本机 `fang123.loupan` 添加三字段（已验证字段存在）

- admin 编译成功
- 后端 jar 编译成功（`fang123-backend-1.0.1-SNAPSHOT.jar`）
