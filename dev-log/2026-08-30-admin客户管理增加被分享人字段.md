# 2026-08-30 admin 客户管理增加"被分享人"字段

## 需求

`http://localhost:3002/admin/customers` 客户管理列表，在"所属用户"列后增加"被分享人"字段，展示该客户被分享给了哪些用户。

## 改动

### 后端

1. **`Customer.java`**：新增非表字段 `sharedTo`（被分享人昵称，多个用"、"分隔）

2. **`CustomerController.java`**：
   - 注入 `CustomerShareService`
   - 新增 `fillSharedTo` 方法：按当前页客户 ID 查询 `customer_shares`，关联 `user_info` 取被分享人昵称，填充到 `sharedTo`
   - 列表接口 `GET /api/admin/customers` 与详情接口均调用 `fillSharedTo`

### 前端（admin/src/views/CustomerManage.vue）

- 表格 `cols` 中"所属用户"后新增 `sharedTo` 列（宽度 130）
- 新增 `#sharedTo` 插槽：有值时展示昵称列表，无值时显示 "-"

## 验证

- 后端编译重启成功，接口实测：客户"孙先生"被分享人正确返回"刘三石"，未分享客户返回空
- admin 编译通过，dev 已热更新（3002 端口）
