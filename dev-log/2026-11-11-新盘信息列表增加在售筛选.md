# 2026-11-11 新盘信息列表增加「在售」等销售状态筛选

## 需求

`https://hangfang123.com/xinpanlist` 支持按销售状态筛选楼盘（在售 / 待售 / 售罄 / 已交付）。

## 实现（仅前端 `web/src/views/XinpanList.vue`）

后端 `/api/public/loupans` 早已支持 `salesStatus` 参数（逗号分隔，多状态），本次无需改动后端。

### 1. 筛选栏新增销售状态下拉

位于「全部区域」与搜索框之间：

```html
<t-select v-model="salesStatus" :options="salesStatusOptions"
          placeholder="全部状态" clearable class="!w-32" @change="onFilterChange" />
```

选项顺序按使用频率：在售、待售、售罄、已交付，值为 `Loupan.salesStatus` 的码值：

| 文案 | 值 |
| --- | --- |
| 在售 | `1` |
| 待售 | `0` |
| 售罄 | `2` |
| 已交付 | `3` |

（码值来源：`['待售','在售','售罄','已交付'][salesStatus]`，全站统一）

### 2. 请求与重置

- `fetchList()`：`if (salesStatus.value !== '') params.salesStatus = salesStatus.value`，与 `keyword`、`district`、`orderByDistrict` 同时生效
- 「清空筛选」按钮显示条件扩展为 `keyword || district || salesStatus`，`resetFilter()` 一并清空销售状态

### 3. 顺带修复

真实数据 `105-330㎡` 在面积段列（88px）被折成两行，改为 `whitespace-nowrap` 并把列宽调到 94px（1024–1279 断点 86px），保证单行显示且不产生横向滚动。

## 验证

临时插入待售、售罄各 1 条数据（验证后已删除，恢复真实 2 条在售）：

| 场景 | 结果 |
| --- | --- |
| 初始（全部状态） | 4 条：待售盘、在售×2、售罄盘 |
| 选「在售」 | 2 条（滨江兴耀.沐青云、潮映杭园），标题「共 2 个楼盘」 |
| 区域=临安区 + 状态=在售 | 0 条，显示「暂无符合条件的楼盘」+「清空筛选」 |
| 点「清空筛选」 | 恢复 4 条，状态下拉回到「全部状态」 |

- 接口层：`?salesStatus=1` 返回 2 条；不传返回 4 条
- 布局：1440 / 1024 无横向滚动；375 移动端筛选栏两行排布（区域+状态 / 搜索+查询），卡片模式正常
- `npm run build` 通过（13.37s）
