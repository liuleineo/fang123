# 2026-08-31 修复微信登录后补充手机号注册异常

## 问题

线上 `https://hangfang123.com/login` 新用户选择微信登录后，补充手机号界面/功能异常：
- 授权成功后填写手机号+密码点击"完成注册"无响应或失败

## 根因

微信授权码（code）是**一次性**的，首次 `exchangeCode(code)` 后即失效：

1. 前端 `handleWechatCode` 首次调用 `POST /api/auth/wechat/login {code}` → 后端 `exchangeCode` 已消费 code，返回 openid（bound=false）
2. 用户补充手机号后 `completeWxRegister` 再次携带**同一 code** 调用后端 → 后端再次 `exchangeCode(code)` 失败（微信返回 40029 invalid code）
3. 前端 catch 静默吞错，无任何提示 → 表现为"功能异常"

## 改动

### 后端（WechatAuthController.java）

- 新增 `WX_CODE_CACHE`（ConcurrentHashMap）缓存 code → 微信用户信息
- `login` 接口优先从缓存取微信信息，未命中才 `exchangeCode` 并缓存（>1000 条时清空防膨胀）
- 补充手机号注册成功后 `WX_CODE_CACHE.remove(code)` 清理

### 前端（web/src/views/Login.vue）

- `completeWxRegister` 失败时提示后端返回的错误信息（不再静默）
- `handleWechatCode` 首次授权失败时同样给出错误提示

## 验证

- 后端编译重启成功；接口 smoke 测试：无 code 返回"授权码不能为空"，假 code 链路可达微信 API
- web 编译通过（真实微信授权需线上环境验证）
